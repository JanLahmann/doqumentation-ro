Problema estimării fazei

Această secțiune a lecției explică problema estimării fazei. Vom începe cu o scurtă discuție despre teorema spectrală din algebră liniară, apoi vom trece la enunțarea problemei estimării fazei în sine.

Teorema spectrală​

Teorema spectrală este un rezultat important din algebră liniară care afirmă că matricele de un anumit tip, numite matrice normale, pot fi exprimate într-un mod simplu și util. Vom avea nevoie de această teoremă doar pentru matrice unitare în această lecție, dar mai departe în această serie o vom aplica și matricelor hermitice.

Matrice normale​

O matrice pătrată MMM cu intrări numere complexe se numește matrice normală dacă comută cu transpusa sa conjugată: MM†=M†M.M M^{\dagger} = M^{\dagger} M.MM†=M†M.

Orice matrice unitară UUU este normală deoarece

UU†=I=U†U.U U^{\dagger} = \mathbb{I} = U^{\dagger} U.UU†=I=U†U.

Matricele hermitice, care sunt matrice egale cu propria lor transpusă conjugată, reprezintă o altă clasă importantă de matrice normale. Dacă HHH este o matrice hermitică, atunci

HH†=H2=H†H,H H^{\dagger} = H^2 = H^{\dagger} H,HH†=H2=H†H,

deci HHH este normală.

Nu orice matrice pătrată este normală. De exemplu, această matrice nu este normală:

(0100)\begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix}(00​10​)

(Acesta este un exemplu simplu, dar excelent de matrice care este adesea foarte util de luat în considerare.) Nu este normală deoarece

(0100)(0100)†=(0100)(0010)=(1000)\begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix} \begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix}^{\dagger} = \begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix} \begin{pmatrix} 0 & 0\\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0\\ 0 & 0 \end{pmatrix}(00​10​)(00​10​)†=(00​10​)(01​00​)=(10​00​)

în timp ce

(0100)†(0100)=(0010)(0100)=(0001).\begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix}^{\dagger} \begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0\\ 1 & 0 \end{pmatrix} \begin{pmatrix} 0 & 1\\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0\\ 0 & 1 \end{pmatrix}.(00​10​)†(00​10​)=(01​00​)(00​10​)=(00​01​).

Enunțul teoremei​

Iată acum un enunț al teoremei spectrale.

Teoremă

Teorema spectrală: Fie MMM o matrice complexă normală de dimensiune N×NN\times NN×N. Există o bază ortonormată de vectori complexi NNN-dimensionali {∣ψ1⟩,…,∣ψN⟩}\bigl\{ \vert\psi_1\rangle,\ldots,\vert\psi_N\rangle \bigr\}{∣ψ1​⟩,…,∣ψN​⟩} împreună cu numerele complexe λ1,…,λN\lambda_1,\ldots,\lambda_Nλ1​,…,λN​ astfel încât

M=λ1∣ψ1⟩⟨ψ1∣+⋯+λN∣ψN⟩⟨ψN∣.M = \lambda_1 \vert \psi_1\rangle\langle \psi_1\vert + \cdots + \lambda_N \vert \psi_N\rangle\langle \psi_N\vert.M=λ1​∣ψ1​⟩⟨ψ1​∣+⋯+λN​∣ψN​⟩⟨ψN​∣.

Expresia unei matrice în forma

M=∑k=1Nλk∣ψk⟩⟨ψk∣(1)M = \sum_{k = 1}^N \lambda_k \vert \psi_k\rangle\langle \psi_k\vert \tag{1}M=k=1∑N​λk​∣ψk​⟩⟨ψk​∣(1)

se numește în mod obișnuit descompunere spectrală. Observă că dacă MMM este o matrice normală exprimată în forma (1),(1),(1), atunci ecuația

M∣ψj⟩=λj∣ψj⟩M \vert \psi_j \rangle = \lambda_j \vert \psi_j \rangleM∣ψj​⟩=λj​∣ψj​⟩

trebuie să fie adevărată pentru orice j=1,…,N.j = 1,\ldots,N.j=1,…,N. Aceasta este o consecință a faptului că {∣ψ1⟩,…,∣ψN⟩}\bigl\{ \vert\psi_1\rangle,\ldots,\vert\psi_N\rangle \bigr\}{∣ψ1​⟩,…,∣ψN​⟩} este ortonormată:

M∣ψj⟩=(∑k=1Nλk∣ψk⟩⟨ψk∣)∣ψj⟩=∑k=1Nλk∣ψk⟩⟨ψk∣ψj⟩=λj∣ψj⟩M \vert \psi_j \rangle = \left(\sum_{k = 1}^N \lambda_k \vert \psi_k\rangle\langle \psi_k\vert\right)\vert \psi_j\rangle = \sum_{k = 1}^N \lambda_k \vert \psi_k\rangle\langle \psi_k\vert\psi_j \rangle = \lambda_j \vert\psi_j \rangleM∣ψj​⟩=(k=1∑N​λk​∣ψk​⟩⟨ψk​∣)∣ψj​⟩=k=1∑N​λk​∣ψk​⟩⟨ψk​∣ψj​⟩=λj​∣ψj​⟩

Cu alte cuvinte, fiecare număr λj\lambda_jλj​ este o valoare proprie a lui MMM, iar ∣ψj⟩\vert\psi_j\rangle∣ψj​⟩ este un vector propriu corespunzător acelei valori proprii.

  • Exemplul 1. Fie

    I=(1001),\mathbb{I} = \begin{pmatrix}1 & 0\\0 & 1\end{pmatrix},I=(10​01​),

    care este normală. Teorema implică faptul că I\mathbb{I}I poate fi scrisă în forma (1)(1)(1) pentru o anumită alegere a lui λ1,\lambda_1,λ1​, λ2,\lambda_2,λ2​, ∣ψ1⟩,\vert\psi_1\rangle,∣ψ1​⟩, și ∣ψ2⟩.\vert\psi_2\rangle.∣ψ2​⟩. Există mai multe alegeri care funcționează, inclusiv

    λ1=1,λ2=1,∣ψ1⟩=∣0⟩,∣ψ2⟩=∣1⟩.\lambda_1 = 1, \hspace{5pt} \lambda_2 = 1, \hspace{5pt} \vert\psi_1\rangle = \vert 0\rangle, \hspace{5pt} \vert\psi_2\rangle = \vert 1\rangle.λ1​=1,λ2​=1,∣ψ1​⟩=∣0⟩,∣ψ2​⟩=∣1⟩.

    Observă că teorema nu afirmă că numerele complexe λ1,…,λN\lambda_1,\ldots,\lambda_Nλ1​,…,λN​ sunt distincte — același număr complex poate apărea repetat, ceea ce este necesar în acest exemplu. Aceste alegeri funcționează deoarece

    I=∣0⟩⟨0∣+∣1⟩⟨1∣.\mathbb{I} = \vert 0\rangle\langle 0\vert + \vert 1\rangle\langle 1\vert.I=∣0⟩⟨0∣+∣1⟩⟨1∣.

    Într-adevăr, am putea alege {∣ψ1⟩,∣ψ2⟩}\{\vert\psi_1\rangle,\vert\psi_2\rangle\}{∣ψ1​⟩,∣ψ2​⟩} să fie orice bază ortonormată și ecuația va fi adevărată. De exemplu,

    I=∣+⟩⟨+∣+∣−⟩⟨−∣.\mathbb{I} = \vert +\rangle\langle +\vert + \vert -\rangle\langle -\vert.I=∣+⟩⟨+∣+∣−⟩⟨−∣.

  • Exemplul 2. Consideră o operație Hadamard.

    H=12(111−1)H = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 & 1\\[1mm] 1 & -1 \end{pmatrix}H=2​1​(11​1−1​)

    Aceasta este o matrice unitară, deci este normală. Teorema spectrală implică faptul că HHH poate fi scrisă în forma (1),(1),(1), și în particular avem

    H=∣ψπ/8⟩⟨ψπ/8∣−∣ψ5π/8⟩⟨ψ5π/8∣H = \vert\psi_{\pi/8}\rangle \langle \psi_{\pi/8}\vert - \vert\psi_{5\pi/8}\rangle \langle \psi_{5\pi/8}\vertH=∣ψπ/8​⟩⟨ψπ/8​∣−∣ψ5π/8​⟩⟨ψ5π/8​∣

    unde

    ∣ψθ⟩=cos⁡(θ)∣0⟩+sin⁡(θ)∣1⟩.\vert\psi_{\theta}\rangle = \cos(\theta)\vert 0\rangle + \sin(\theta) \vert 1\rangle.∣ψθ​⟩=cos(θ)∣0⟩+sin(θ)∣1⟩.

    Mai explicit,

    ∣ψπ/8⟩=2+22∣0⟩+2−22∣1⟩,∣ψ5π/8⟩=−2−22∣0⟩+2+22∣1⟩.\begin{aligned} \vert\psi_{\pi/8}\rangle & = \frac{\sqrt{2 + \sqrt{2}}}{2}\vert 0\rangle + \frac{\sqrt{2 - \sqrt{2}}}{2}\vert 1\rangle, \\[3mm] \vert\psi_{5\pi/8}\rangle & = -\frac{\sqrt{2 - \sqrt{2}}}{2}\vert 0\rangle + \frac{\sqrt{2 + \sqrt{2}}}{2}\vert 1\rangle. \end{aligned}∣ψπ/8​⟩∣ψ5π/8​⟩​=22+2​​​∣0⟩+22−2​​​∣1⟩,=−22−2​​​∣0⟩+22+2​​​∣1⟩.​

    Putem verifica că această descompunere este corectă efectuând calculele necesare:

    ∣ψπ/8⟩⟨ψπ/8∣−∣ψ5π/8⟩⟨ψ5π/8∣=(2+2424242−24)−(2−24−24−242+24)=H.\vert\psi_{\pi/8}\rangle \langle \psi_{\pi/8}\vert - \vert\psi_{5\pi/8}\rangle \langle \psi_{5\pi/8}\vert = \begin{pmatrix} \frac{2 + \sqrt{2}}{4} & \frac{\sqrt{2}}{4}\\[2mm] \frac{\sqrt{2}}{4} & \frac{2 - \sqrt{2}}{4} \end{pmatrix} - \begin{pmatrix} \frac{2 - \sqrt{2}}{4} & -\frac{\sqrt{2}}{4}\\[2mm] -\frac{\sqrt{2}}{4} & \frac{2 + \sqrt{2}}{4} \end{pmatrix} = H.∣ψπ/8​⟩⟨ψπ/8​∣−∣ψ5π/8​⟩⟨ψ5π/8​∣=​42+2​​42​​​42​​42−2​​​​−​42−2​​−42​​​−42​​42+2​​​​=H.

După cum relevă primul exemplu de mai sus, poate exista o anumită libertate în modul în care sunt aleși vectorii proprii. Nu există însă nicio libertate în modul în care sunt alese valorile proprii, cu excepția ordinii lor: aceleași NNN numere complexe λ1,…,λN,\lambda_1,\ldots,\lambda_N,λ1​,…,λN​, care pot include repetări ale aceluiași număr complex, vor apărea întotdeauna în ecuația (1)(1)(1) pentru o alegere dată a matricei M.M.M.

Să ne concentrăm acum pe matricele unitare. Presupunem că avem un număr complex λ\lambdaλ și un vector nenul ∣ψ⟩\vert\psi\rangle∣ψ⟩ care satisfac ecuația

U∣ψ⟩=λ∣ψ⟩.(2)U\vert\psi\rangle = \lambda\vert\psi\rangle. \tag{2}U∣ψ⟩=λ∣ψ⟩.(2)

Adică, λ\lambdaλ este o valoare proprie a lui UUU și ∣ψ⟩\vert\psi\rangle∣ψ⟩ este un vector propriu corespunzător acestei valori proprii.

Matricele unitare păstrează norma euclidiană, astfel că deducem următoarele din (2).(2).(2).

∥∣ψ⟩∥=∥U∣ψ⟩∥=∥λ∣ψ⟩∥=∣λ∣∥∣ψ⟩∥\bigl\| \vert\psi\rangle \bigr\| = \bigl\| U \vert\psi\rangle \bigr\| = \bigl\| \lambda \vert\psi\rangle \bigr\| = \vert \lambda \vert \bigl\| \vert\psi\rangle \bigr\|​∣ψ⟩​=​U∣ψ⟩​=​λ∣ψ⟩​=∣λ∣​∣ψ⟩​

Condiția că ∣ψ⟩\vert\psi\rangle∣ψ⟩ este nenul implică ∥∣ψ⟩∥≠0,\bigl\| \vert\psi\rangle \bigr\|\neq 0,​∣ψ⟩​=0, deci putem elimina acest factor din ambii membri și obținem

∣λ∣=1.\vert \lambda \vert = 1.∣λ∣=1.

Aceasta arată că valorile proprii ale matricelor unitare trebuie să aibă întotdeauna valoarea absolută egală cu unu, deci se află pe cercul unitate.

T={α∈C:∣α∣=1}\mathbb{T} = \{\alpha\in\mathbb{C} : \vert\alpha\vert = 1\}T={α∈C:∣α∣=1}

(Simbolul T\mathbb{T}T este un nume uzual pentru cercul unitate complex. Numele S1S^1S1 este de asemenea frecvent utilizat.)

Enunțul problemei de estimare a fazei​

În problema estimării fazei, ni se dă o stare cuantică ∣ψ⟩\vert \psi\rangle∣ψ⟩ pe nnn qubiți, împreună cu un circuit cuantic unitar care acționează pe nnn qubiți. Se garantează că ∣ψ⟩\vert \psi\rangle∣ψ⟩ este un vector propriu al matricei unitare UUU care descrie acțiunea circuitului, iar scopul nostru este să calculăm sau să aproximăm valoarea proprie λ\lambdaλ căreia îi corespunde ∣ψ⟩.\vert \psi\rangle.∣ψ⟩. Mai precis, deoarece λ\lambdaλ se află pe cercul unitate complex, putem scrie

λ=e2πiθ\lambda = e^{2\pi i \theta}λ=e2πiθ

pentru un număr real unic θ\thetaθ care satisface 0≤θ<1.0\leq\theta<1.0≤θ<1. Scopul problemei este să calculăm sau să aproximăm acest număr real θ.\theta.θ.

Problema estimării fazei

Intrare: Un circuit cuantic unitar pentru o operație UUU pe nnn qubiți, împreună cu o stare cuantică ∣ψ⟩\vert\psi\rangle∣ψ⟩ pe nnn qubiți
Promisiune: ∣ψ⟩\vert\psi\rangle∣ψ⟩ este un vector propriu al lui UUU
Ieșire: o aproximare a numărului θ∈[0,1)\theta\in[0,1)θ∈[0,1) care satisface U∣ψ⟩=e2πiθ∣ψ⟩U\vert\psi\rangle = e^{2\pi i \theta}\vert\psi\rangleU∣ψ⟩=e2πiθ∣ψ⟩

Iată câteva observații despre acest enunț al problemei:

  1. Problema estimării fazei este diferită de alte probleme văzute până acum în curs prin faptul că intrarea include o stare cuantică. De obicei ne concentrăm pe probleme cu intrări și ieșiri clasice, dar nimic nu ne împiedică să luăm în considerare intrări sub formă de stări cuantice ca aceasta. Din perspectiva relevanței practice, problema estimării fazei este întâlnită de obicei ca o subproblemă în cadrul unui calcul mai mare, cum vom vedea în contextul factorizării numerelor întregi mai târziu în lecție.

  2. Enunțul problemei de estimare a fazei de mai sus nu specifică ce constituie o aproximare a lui θ,\theta,θ, dar putem formula enunțuri mai precise ale problemei în funcție de nevoile și interesele noastre. În contextul factorizării numerelor întregi, vom cere o aproximare foarte precisă a lui θ,\theta,θ, dar în alte cazuri s-ar putea să fim mulțumiți cu o aproximare foarte grosieră. Vom discuta în scurt timp cum precizia necesară afectează costul computațional al unei soluții.
