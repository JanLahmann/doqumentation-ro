Rezonanță magnetică nucleară cu Qiskit

Pentru acest modul Qiskit in Classrooms, studenții trebuie să aibă un mediu Python funcțional, cu următoarele pachete instalate:

  • qiskit v2.1 sau mai nou
  • qiskit-ibm-runtime v0.40.1 sau mai nou
  • qiskit-aer v0.17 sau mai nou
  • scipy și matplotlib (pentru ajustare și trasare)
  • pylatexenc (pentru randarea diagramelor de circuit)

Pentru a configura și a instala pachetele de mai sus, consultă ghidul Install Qiskit. Pentru a rula joburi pe computere cuantice reale, studenții trebuie să creeze un cont IBM Quantum® urmând pașii din ghidul Set up your IBM Cloud® account.

Acest modul a fost testat și folosește aproximativ 5 minute de timp QPU. Aceasta este o estimare, iar utilizarea ta reală poate varia.

Introducere​

Când un chimist rulează un experiment RMN, plasează o probă de spini nucleari într-un câmp magnetic puternic, aplică un impuls de radiofrecvență (RF) și măsoară semnalul care revine. Tehnica se bazează pe câteva idei din mecanica cuantică a unei particule cu spin 1/2 într-un câmp magnetic. Spinul are două niveluri de energie separate de o energie care corespunde unei frecvențe Larmor caracteristice. Un impuls rezonant la acea frecvență înclină spinul în planul transversal, unde acesta execută o mișcare de precesie și induce un semnal care apoi se estompează cu doi timpi caracteristici, T1T_1T1​ și T2T_2T2​.

Un qubit supraconductor este o versiune concepută artificial a aceluiași obiect: un sistem cuantic controlabil cu două niveluri. Stările sale ∣0⟩|0\rangle∣0⟩ și ∣1⟩|1\rangle∣1⟩ sunt analogul spinului în sus și al spinului în jos, poarta pe care o aplicăm pentru a-l roti este analogul impulsului RF, iar el pierde coerența cu propriii T1T_1T1​ și T2T_2T2​. Aceasta nu este doar o comparație vagă; unele dintre primele procesoare cuantice experimentale de la sfârșitul anilor 1990 și începutul anilor 2000 au folosit RMN.

În acest modul vei folosi un computer cuantic real pentru a rula aceleași experimente de caracterizare pe care le efectuează un spectroscopist RMN (sau un inginer cuantic care calibrează hardware-ul):

  • Rabi / nutație — acționarea spinului și observarea rotației sale. Așa calibrezi o rotație de π\piπ sau π/2\pi/2π/2.

  • T1T_1T1​ — relaxarea spin-rețea, revenirea unui spin excitat la echilibru.

  • T2T_2T2​ — relaxarea spin-spin (defazare), măsurată cu un experiment Ramsey și refocalizată cu un ecou Hahn.

  • Spectroscopie RMN (deplasare chimică și cuplaj JJJ) — simularea unei molecule mici pe mai mulți qubiți și citirea spectrului ei de multipleți pentru a recupera conectivitatea prin regula n+1n+1n+1.

Pentru fiecare concept oferim mai întâi teoria minimă, apoi implementăm experimentul în Qiskit urmând fluxul de lucru în patru pași Qiskit patterns.

Teorie​

Particule cu spin 1/2 într-un câmp magnetic​

Un nucleu cu spin 1/2 are un moment magnetic μ=γℏI\boldsymbol{\mu} = \gamma \hbar \mathbf{I}μ=γℏI, unde γ\gammaγ este raportul giromagnetic. Într-un câmp static B0B_0B0​ de-a lungul axei zzz, cele două stări de spin se despart energetic (efectul Zeeman):

E±=∓12γℏB0,ΔE=γℏB0=ℏω0.E_{\pm} = \mp \tfrac{1}{2}\gamma \hbar B_0, \qquad \Delta E = \gamma \hbar B_0 = \hbar \omega_0 .E±​=∓21​γℏB0​,ΔE=γℏB0​=ℏω0​.

Diferența de energie definește frecvența Larmor (de rezonanță) ω0=γB0\omega_0 = \gamma B_0ω0​=γB0​. Momentul magnetic execută o precesie în jurul lui B0B_0B0​ la această aceeași frecvență.

Pentru a roti spinul aplicăm un câmp RF oscilant la (sau aproape de) ω0\omega_0ω0​. În sistemul de referință care se rotește cu frecvența de acționare (sistemul rotitor), o acționare rezonantă rotește vectorul Bloch în jurul unei axe din planul xxx-yyy. Cât de mult se rotește (unghiul de basculare) este stabilit de intensitatea și durata impulsului. Două alegeri contează cel mai mult: un impuls de 90∘90^\circ90∘ înclină un spin +1/2+1/2+1/2 în planul transversal, iar un impuls de 180∘180^\circ180∘ îl rotește complet la −1/2-1/2−1/2.

Un qubit este un sistem cu două niveluri, identic matematic cu un spin 1/2 într-un câmp magnetic — așadar, chiar dacă rulăm pe un procesor cuantic și nu pe un nucleu, fizica este aceeași fizică ce stă la baza RMN. import numpy as np
from itertools import combinations
from qiskit_aer import AerSimulator
from qiskit.transpiler import generate_preset_pass_manager
from qiskit_ibm_runtime import EstimatorV2 as Estimator

USE_HARDWARE = True  # <-- set True to run on the QPU selected above
USE_BATCH = False  # Safer for a class with pauses; set True for an uninterrupted run

if USE_HARDWARE:
    run_backend = backend  # the real QPU selected above
else:
    # Local testing mode: an Aer simulator that mimics the selected device -- its noise model,
    # coupling map, and qubit count -- while layout choices still use real calibration data.
    run_backend = AerSimulator.from_backend(backend)

# --- Choose connected qubits with low readout error. --------------------------------------
def readout_error(q):
    props = backend.target["measure"].get((q,))
    return props.error if props is not None and props.error is not None else 1.0

coupling_map = backend.coupling_map or backend.target.build_coupling_map()
edges = {tuple(sorted(edge)) for edge in coupling_map.get_edges() if edge[0] != edge[1]}

# AX needs one connected pair.
AX_LAYOUT = list(min(edges, key=lambda edge: sum(readout_error(q) for q in edge)))

# AX2 needs one qubit connected to two neighbours; the first entry is the central A qubit.
neighbors = {q: set() for q in range(backend.num_qubits)}
for q0, q1 in edges:
    neighbors[q0].add(q1)
    neighbors[q1].add(q0)
ax2_layouts = (
    [a, x1, x2]
    for a, adjacent in neighbors.items()
    for x1, x2 in combinations(adjacent, 2)
)
AX2_LAYOUT = min(ax2_layouts, key=lambda layout: sum(readout_error(q) for q in layout))

# Use a long-lived qubit for the single-qubit experiments.
def best_qubit(backend):
    return max(
        range(backend.num_qubits), key=lambda q: backend.qubit_properties(q).t2 or 0.0
    )

QUBIT = best_qubit(backend)
qp = backend.qubit_properties(QUBIT)
print(
    f"Using qubit {QUBIT} for single-qubit experiments: "
    f"T1 = {qp.t1 * 1e6:.0f} us, T2 = {qp.t2 * 1e6:.0f} us"
)
print(f"Using physical qubits {AX_LAYOUT} for AX")
print(f"Using physical qubits {AX2_LAYOUT} for AX2 (A first, then the two X spins)")

pm_q = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=[QUBIT]
)
pm_ax = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX_LAYOUT
)
pm_ax2 = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX2_LAYOUT
)

# Job mode is the default because a classroom pause can deactivate a Batch. On the Open plan,
# a Batch has a 10-minute maximum lifetime and deactivates after 1 minute with no queued job.
batch = Batch(backend=run_backend) if USE_BATCH else None
execution_mode = batch if batch is not None else run_backend
sampler = Sampler(mode=execution_mode)
estimator = Estimator(mode=execution_mode)
estimator.options.resilience_level = 0  # raw expectation values, no error mitigation
estimator.options.default_shots = 1000

mode_name = "Batch" if USE_BATCH else "individual jobs"
device_name = "hardware" if USE_HARDWARE else "local simulator (runtime local mode)"
print(f"Ready. Running on {device_name} using {mode_name}.")

Experiment: oscilații Rabi (nutație)​

Teorie​

Acționează un spin la rezonanță și vectorul său Bloch se rotește constant de la un pol la celălalt — execută o nutație. Dacă aplicăm o rotație cu unghiul de basculare θ\thetaθ în jurul axei xxx unui qubit care pornește din ∣0⟩|0\rangle∣0⟩, probabilitatea de a-l găsi în ∣1⟩|1\rangle∣1⟩ este:

P1(θ)=sin⁡2 ⁣(θ2)=12(1−cos⁡θ).P_1(\theta) = \sin^2\!\left(\tfrac{\theta}{2}\right) = \tfrac{1}{2}\bigl(1 - \cos\theta\bigr).P1​(θ)=sin2(2θ​)=21​(1−cosθ).

Aceasta este curba Rabi. Primul ei maxim este impulsul π\piπ (inversiune completă, impulsul de 180∘180^\circ180∘); un impuls π/2\pi/2π/2 este un sfert de tură (impulsul de 90∘90^\circ90∘ care înclină un spin în planul transversal). În RMN, această curbă este modul în care calibrezi impulsurile.

Avertisment experimental

Un experiment Rabi literal variază în timp amplitudinea sau durata acționării. Aceasta necesită control la nivel de impuls, care a fost eliminat în Qiskit v2.0. Aici variem în schimb unghiul de rotație θ\thetaθ al unei porți RX(θ)R_X(\theta)RX​(θ). Curba și identificarea π\piπ/π/2\pi/2π/2 sunt identice; singura diferență este că alegem direct un unghi, în loc să calibrăm o durată de impuls. Pe hardware cu porți fracționare, RX(θ)R_X(\theta)RX​(θ) pentru θ\thetaθ arbitrar rulează nativ.

O vedere pe sfera Bloch​

Animația de mai jos arată nutația: o acționare rezonantă rotește constant vectorul Bloch în jurul axei xxx, ducându-l de la ∣0⟩|0\rangle∣0⟩ spre ∣1⟩|1\rangle∣1⟩ și înapoi. Aceasta este chiar mișcarea pe care o măsoară curba Rabi.

Mapează problema pe un circuit​

Construim un circuit parametrizat, RX(θ)R_X(\theta)RX​(θ) urmat de o măsurătoare, și îl evaluăm ulterior la mai multe unghiuri simultan.

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

theta = Parameter("theta")

rabi.rx(theta, 0)
rabi.measure(0, 0)
rabi.draw("mpl")

Optimizare pentru execuție​

Transpilează într-un circuit Instruction Set Architecture (ISA) pentru backend-ul ales.

rabi_isa = pm_q.run(rabi)

Execută​

Variem θ\thetaθ de la 000 la 4π4\pi4π (două cicluri Rabi complete). Transmiterea unui array de valori ale parametrilor ca un singur Primitive Unified Bloc (PUB) le rulează pe toate într-un singur job.

angles = np.linspace(0, 4 * np.pi, 41)
job = sampler.run([(rabi_isa, angles.reshape(-1, 1))], shots=1000)
rabi_result = job.result()

Extrage P1P_1P1​ la fiecare unghi și compară cu sin⁡2(θ/2)\sin^2(\theta/2)sin2(θ/2).

Răspuns

(a) Maximul apare acolo unde rotația reală este egală cu π\piπ, adică la unghiul nominal θ=π/1.05≈0.95π\theta = \pi/1.05 \approx 0.95\piθ=π/1.05≈0.95π — o mică deplasare a vârfului spre stânga.

Revenim la această idee în problemele provocatoare.

Experiment: T1T_1T1​ (relaxare spin-rețea)​

Teorie​

Lăsat singur, un spin excitat cedează energie mediului înconjurător („rețeaua”) și revine spre echilibrul termic. Populația stării excitate scade exponențial cu timpul de relaxare spin-rețea T1T_1T1​:

P1(τ)=e−τ/T1.P_1(\tau) = e^{-\tau/T_1}.P1​(τ)=e−τ/T1​.

Pentru un chimist, T1T_1T1​ stabilește întârzierea de reciclare pe care trebuie s-o aștepți între scanări pentru RMN cantitativ și oferă informații despre rotirea moleculară și dinamică. Pe un qubit este timpul de relaxare a energiei și este unul dintre cele două numere principale folosite pentru a modela efectele de decoerență într-un computer cuantic.

Experimentul. Pregătește ∣1⟩|1\rangle∣1⟩ cu o poartă XXX (un puls π\piπ), așteaptă o întârziere variabilă τ\tauτ, apoi măsoară. Fracțiunea rămasă în ∣1⟩|1\rangle∣1⟩ trasează descreșterea.

O vizualizare pe sfera Bloch​

Relaxarea T1T_1T1​ readuce starea excitată la echilibru, astfel încât vectorul Bloch alunecă de la ∣1⟩|1\rangle∣1⟩ înapoi la ∣0⟩|0\rangle∣0⟩ de-a lungul axei zzz.

Construiește și transpilează o scanare a întârzierii​

Duratele întârzierilor trebuie să fie valori concrete (sunt programate în timpul hardware), așa că construim câte un circuit pentru fiecare întârziere.

# Scale the T1 delay sweep to the qubit's reported coherence, and snap each delay to an integer
# number of samples (dt) so there are no "duration rounded" warnings (as in the Ramsey/echo cells).
T1_us = (backend.qubit_properties(QUBIT).t1 or 100e-6) * 1e6  # reported T1 (us)
delays_us = np.linspace(0, 5 * T1_us, 20)  # 0 .. ~5 T1 captures the full decay
print(f"T1 sweep: 0..{5*T1_us:.0f} us in {len(delays_us)} points")

dt = backend.dt
t1_circuits = []
for tau in delays_us:
    n_dt = int(round(tau * 1e-6 / dt))  # integer samples -> no rounding warning
    qc = QuantumCircuit(1, 1)
    qc.x(0)  # pi pulse: prepare |1>
    qc.delay(n_dt, 0, unit="dt")  # wait tau
    qc.measure(0, 0)
    t1_circuits.append(qc)

t1_isa = pm_q.run(t1_circuits)
T1 sweep: 0..1393 us in 20 points

Execută​

t1_job = sampler.run([(c,) for c in t1_isa], shots=1000)
t1_res = t1_job.result()

Analiză — potrivirea exponențialei​

from scipy.optimize import curve_fit

p1_t1 = np.array(
    [r.data.c.get_counts().get("1", 0) / r.data.c.num_shots for r in t1_res]
)

def decay(t, A, T1, B):
    return A * np.exp(-t / T1) + B

p0 = [1.0, 100.0, 0.0]
popt, _ = curve_fit(decay, delays_us, p1_t1, p0=p0, maxfev=10000)
T1_fit = popt[1]

plt.figure(figsize=(7, 4))
plt.plot(delays_us, p1_t1, "o", label="measured")
tt = np.linspace(0, delays_us.max(), 200)
plt.plot(tt, decay(tt, *popt), "-", label=rf"fit: $T_1$ = {T1_fit:.1f} µs")
plt.xlabel("delay τ (µs)")
plt.ylabel(r"$P_1$")
plt.title("$T_1$ relaxation")
plt.legend()
plt.tight_layout()
plt.show()
print(f"Measured T1 = {T1_fit:.1f} microseconds")

Experiment: T2T_2T2​, T2∗T_2^*T2∗​​

Teorie​

T1T_1T1​ măsoară pierderea de energie. T2T_2T2​ măsoară pierderea coerenței de fază în planul transversal. O putem observa cu un experiment Ramsey: un puls π/2\pi/2π/2 rotește toate spinurile până la ecuator, toate indicând în aceeași direcție. Ele execută precesie Larmor, dar fiecare precesează cu o frecvență ușor diferită, așa că se desfac în evantai de-a lungul ecuatorului, iar semnalul transversal net scade, cu un timp caracteristic de descreștere T2∗T_2^*T2∗​.

O paranteză pentru cititorii cuantici: Imaginea evantaiului arată o modalitate de a pierde coerența: o dispersie de faze definite care se anulează în medie. Merită să știi că nu este singurul mecanism. Coerența se poate pierde și pentru că faza se încâlcește (entanglement) cu mediul, astfel încât nu mai este deloc o valoare definită pe care o deține sistemul. Nu poți distinge cele două mecanisme doar urmărind descreșterea semnalului, deci imaginea evantaiului este o bună intuiție. Ai grijă să nu o citești ca pe povestea completă sau literală.

Două efecte defazează un spin:

  • Decoerența ireversibilă (sau efectiv ireversibilă), provenită din cuplajul necontrolat cu alte grade de libertate, caracterizată de adevăratul T2T_2T2​. În RMN, aceasta provine în general din mișcarea moleculară care modulează cuplajele dintre spinuri. În calculul cuantic, corespunde cuplajelor nedorite dintre qubiți și mediu.
  • Decalaje de frecvență statice sau lent variabile, reversibile, precum neomogenitatea câmpului, variația de frecvență de la un qubit la altul și erorile de calibrare. Combinate cu adevăratul T2T_2T2​, acestea produc timpul de descreștere aparent, mai scurt, T2∗T_2^*T2∗​, observat într-un experiment Ramsey.

Deci cum aflăm adevăratul T2T_2T2​ dacă un experiment Ramsey ne spune doar despre T2∗T_2^*T2∗​? Al doilea experiment, numit ecou Hahn, anulează tot zgomotul de al doilea tip pentru a găsi adevăratul T2T_2T2​. Începe la fel ca un experiment Ramsey, cu un puls π/2\pi/2π/2, apoi spinurile se desfac în evantai ca înainte. După un timp τ\tauτ, se aplică un puls π\piπ. Pulsul inversează acumularea de fază cauzată de decalajele statice de frecvență, astfel încât spinurile se refocalizează după o a doua întârziere de aceeași durată, τ\tauτ.

T2∗T_2^*T2∗​ și T2T_2T2​ sunt ambele numere importante de cunoscut, atât în chimie, cât și în calculul cuantic. În chimie, T2∗T_2^*T2∗​ stabilește lățimea liniei pentru un experiment RMN standard (vei vedea ce înseamnă aceasta într-o secțiune ulterioară). T2T_2T2​ ne poate spune multe despre molecule, precum rotirea moleculară, iar o schimbare a lui T2T_2T2​ poate semnala că o moleculă s-a legat de ceva mai mare. În calculul cuantic, în general vrem ca atât T2T_2T2​, cât și T2∗T_2^*T2∗​ să fie cât mai lungi, pentru a avea mai mult timp să efectuăm experimente înainte ca decoerența să copleșească sistemul. O întreagă familie de tehnici bazate pe ecoul Hahn prelungește acest timp anulând zgomotul reversibil, astfel încât circuitul să fie limitat în mod ideal de adevăratul T2T_2T2​, nu de T2∗T_2^*T2∗​. Aceasta se numește „decuplare dinamică”.

Implementare​

Când implementăm experimentele Ramsey și ecou Hahn pe un qubit, citirea este ușor diferită față de cazul RMN. În RMN poți observa direct câmpurile oscilante induse de spinurile care execută precesie la frecvența Larmor în planul transversal. Dar cu un qubit putem măsura doar proiecția lui pe axa ZZZ, adică dacă este ∣0⟩\vert 0 \rangle∣0⟩ sau ∣1⟩\vert 1 \rangle∣1⟩. Prin urmare, pentru ambele experimente încheiem cu un puls π/2\pi/2π/2 suplimentar, urmat de o măsurătoare. Acest puls π/2\pi/2π/2 traduce informația de fază a qubitului într-o populație.

Mai jos rulăm fiecare experiment pentru a determina T2∗T_2^*T2∗​ și T2T_2T2​.

Ramsey (T2∗T_2^{*}T2∗​): Două pulsuri π/2\pi/2π/2 cu timpul de întârziere τ\tauτ​

Primul puls π/2\pi/2π/2 înclină vectorul Bloch până la ecuator, iar următorul traduce faza vectorului Bloch într-o populație. Deoarece faza se schimbă în timp pe măsură ce vectorul Bloch execută precesie, vedem un model sinusoidal în populație în funcție de timpul de precesie τ\tauτ. Pe măsură ce qubitul pierde coerența de fază, ar trebui să vedem amplitudinea acestei sinusoide scăzând.

Câteva subtilități în plus pentru cititorii cuantici: În experimentele de calcul cuantic, oscilațiile pe care le vedem nu sunt de fapt la frecvența Larmor, care este în domeniul GHz și mult prea rapidă pentru a fi rezolvată. Experimentele cuantice operează în sistemul de referință rotitor: un sistem care se rotește odată cu qubitul la (aproape) frecvența Larmor, astfel încât precesia rapidă este invizibilă, iar vectorul Bloch pare aproape nemișcat. Pentru a vedea franje, setăm în mod deliberat sistemul de referință rotitor ușor decalat față de frecvența Larmor. Vectorul Bloch pare atunci să execute precesie la acel mic decalaj, și obținem un semnal oscilant la frecvența decalajului. Mai jos nu fixăm decalajul la o singură valoare; îl alegem astfel încât aproximativ o duzină de franje să cuprindă fereastra de măsurare (pe care o dimensionăm după timpul de coerență al qubitului), ceea ce păstrează oscilația ușor de eșantionat fără aliasing. Încă o complicație: în Qiskit nu avem controlul la nivel de puls necesar pentru a schimba frecvența pulsului (care este cea care stabilește frecvența sistemului de referință rotitor). În schimb, adăugăm manual un decalaj efectiv, folosindu-l pentru a seta faza celui de-al doilea puls Ramsey. Este puțin artificial, dar rezultatul este același, iar descreșterea pe care o observăm este în continuare adevăratul T2∗T_2^*T2∗​.

O vizualizare pe sfera Bloch​

Un puls π/2\pi/2π/2 înclină spinurile până la ecuator; fiecare execută apoi precesie cu o viteză ușor diferită și se desfac în evantai, astfel încât vectorul net (roșu) se micșorează pe măsură ce se defazează — această descreștere este T2∗T_2^*T2∗​.

Spectroscopia RMN a unei molecule: deplasarea chimică și cuplajul JJJ​

De la un spin la o moleculă​

Experimentele de până acum au caracterizat un singur spin izolat. RMN-ul chimic real citește o moleculă (multe spinuri cuplate simultan) și folosește spectrul rezultat pentru a deduce trăsături ale structurii moleculei. Acesta ne poate spune despre două efecte:

  • Deplasarea chimică. Fiecare nucleu distinct chimic execută precesie cu o frecvență ușor diferită νi\nu_iνi​, deoarece electronii săi locali ecranează câmpul aplicat în măsuri diferite. Pozițiile vârfurilor identifică, prin urmare, mediile chimice (de exemplu un proton CH3_33​ față de unul aromatic).

  • Cuplajul scalar JJJ. O interacțiune prin legături între două spinuri împarte fiecare vârf într-un multiplet. Un nucleu cu nnn vecini echivalenți este împărțit în n+1n+1n+1 linii cu intensități binomiale, regula n+1n+1n+1. Modelul de despicare dezvăluie conectivitatea (care nuclee sunt legate), iar distanța dintre linii este constanta de cuplaj JJJ.

Experimentul​

Pentru a modela aceasta în computerul nostru cuantic, trebuie să implementăm un hamiltonian de spin pe qubiți. În limita cuplajului slab și a câmpului intens (diferențe de deplasare chimică ≫\gg≫ cuplaje), părțile XXXXXX și YYYYYY ale cuplajului se anulează în medie, lăsând doar ZZZZZZ. Astfel, hamiltonianul este (în unități de frecvență unghiulară, ℏ=1\hbar=1ℏ=1):

H=∑iπ νi Zi⏟chemical shift  +  ∑i<jπ2 Jij ZiZj⏟J-coupling.H = \underbrace{\sum_i \pi\,\nu_i\, Z_i}_{\text{chemical shift}} \;+\; \underbrace{\sum_{i<j} \tfrac{\pi}{2}\,J_{ij}\, Z_iZ_j}_{J\text{-coupling}}.H=chemical shifti∑​πνi​Zi​​​+J-couplingi<j∑​2π​Jij​Zi​Zj​​​.

Fiecare nucleu este un qubit: deplasarea chimică este o rotație ZZZ pe un singur qubit, iar cuplajul este o interacțiune ZZZZZZ pe doi qubiți.

Experimentul decurge astfel. Un puls π/2\pi/2π/2 înclină fiecare spin în planul transversal, iar spinurile execută precesie și se cuplează timp de ttt. Înregistrăm magnetizarea transversală complexă s(t)=⟨X⟩+i⟨Y⟩s(t) = \langle X\rangle + i\langle Y\rangles(t)=⟨X⟩+i⟨Y⟩ însumată peste toate spinurile. Ca în experimentul Ramsey de mai sus, această magnetizare transversală trasează o sinusoidă descrescătoare în funcție de timpul de precesie ttt. Când luăm transformata Fourier a semnalului, obținem un spectru cu vârfuri la deplasarea chimică νi\nu_iνi​, despicate de cuplajul scalar JijJ_{ij}Jij​.

notă

Simulăm evoluția moleculei transformând timpul ttt în unghiuri de rotație: un ttt mai mare înseamnă rotații ZZZ și ZZZZZZ mai mari, nu un circuit mai lung sau mai adânc. Așadar, deși starea simulată avansează cu ttt (asta face ca descreșterea liberă prin inducție (FID) să oscileze), qubiții fizici nu stau niciodată inactivi mai mult timp și nu există decoerență dependentă de ttt. FID-ul simulat nu scade deci niciodată de la sine. Pentru un FID ideal infinit de lung, liniile spectrale ar fi infinit de înguste; fereastra noastră finită de eșantionare le dă în schimb o rezoluție finită și poate introduce scurgere spectrală. Liniile RMN reale au o lățime finită stabilită de T2∗T_2^*T2∗​. O adăugăm la loc înmulțind FID-ul cu o fereastră e−t/T2∗e^{-t/T_2^{*}}e−t/T2∗​ înainte de transformata Fourier. Aceasta se numește apodizare cu lărgire de linie, pe care spectroscopiștii o aplică în procesare pentru a stabili lățimea liniei (sacrificând rezoluția pentru raportul semnal-zgomot). (O celulă opțională din Anexa acestui modul arată o alternativă Trotterizată, în care descreșterea provine în schimb din decoerența reală, care crește cu adâncimea circuitului.)

Sistemul AX​

Să începem cu așa-numitul sistem AX, o moleculă formată din două spinuri cuplate, distincte chimic. Etichetele A și X denotă cele două medii de spin distincte chimic. Literele sunt arbitrare, dar faptul că sunt departe în alfabet ilustrează deosebirea lor chimică.

Mapare și optimizare​

Scriem o funcție care, date fiind decalajele de deplasare chimică νi\nu_iνi​ și cuplajele JijJ_{ij}Jij​, returnează un circuit parametrizat de pregătire a stării. Pulsul π/2\pi/2π/2 înclină spinurile până la ecuator, apoi rotațiile ZZZ simulează evoluția stării sub termenii de deplasare chimică și de cuplaj JJJ. Fiecare νi\nu_iνi​ este un mic decalaj de precesie în Hz față de o referință aleasă, sau purtătoarea sistemului de referință rotitor. Aici îl setăm manual; într-o moleculă reală, ecranarea electronică schimbă câmpul magnetic local și deplasează rezonanța fiecărui nucleu față de acea referință. Aceasta este modelată de porțile RZR_ZRZ​ pe un singur qubit, câte una pentru fiecare spin, iar fiecare νi\nu_iνi​ fixează unde se află vârful acelui spin în spectru. Poarta ZZZZZZ pe doi qubiți aplică cuplajul JijJ_{ij}Jij​, care împarte fiecare vârf într-un multiplet și stabilește distanța dintre liniile sale.

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit.quantum_info import SparsePauliOp

t = Parameter(
    "t"
)  # evolution time (arbitrary units; the frequencies below are in matching units)

def fid_circuit(offsets, couplings):
    """State-preparation circuit for a set of spins: a pi/2 pulse, then evolution under the
    chemical-shift + J-coupling Hamiltonian for time t. No measurement -- the Estimator reads
    <X> and <Y> directly.

    offsets   : list of chemical-shift frequencies nu_i, one per qubit
    couplings : dict {(i, j): J_ij}
    """
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # pi/2 pulse: tip every spin into the transverse plane
    for i, nu in enumerate(offsets):
        qc.rz(2 * np.pi * nu * t, i)  # chemical-shift precession -> line at nu_i
    for (i, j), J in couplings.items():
        qc.rzz(np.pi * J * t, i, j)  # J-coupling -> splitting of size J
    return qc

def transverse_obs(n):
    """Total transverse observables (sum over spins): (sum_i X_i, sum_i Y_i)."""
    ox = SparsePauliOp.from_sparse_list(
        [("X", [i], 1.0) for i in range(n)], num_qubits=n
    )
    oy = SparsePauliOp.from_sparse_list(
        [("Y", [i], 1.0) for i in range(n)], num_qubits=n
    )
    return ox, oy

# AX system: two distinct chemical shifts, one coupling
ax_offsets = [6.0, -6.0]  # chemical shifts nu_1, nu_2 (Hz)
ax_couplings = {(0, 1): 2.0}  # J_12 = 2 Hz

ax_isa = pm_ax.run(fid_circuit(ax_offsets, ax_couplings))
fid_circuit(ax_offsets, ax_couplings).draw("mpl")

Execută și post-procesează​

Evaluăm circuitul pe o grilă de timpi de evoluție, iar Estimator returnează ⟨X⟩\langle X\rangle⟨X⟩ și ⟨Y⟩\langle Y\rangle⟨Y⟩ pentru fiecare. Le combinăm în FID-ul complex ⟨X⟩+i⟨Y⟩\langle X\rangle + i\langle Y\rangle⟨X⟩+i⟨Y⟩, aplicăm fereastra de apodizare și aplicăm transformata Fourier rezultatului pentru a obține spectrul.

# --- time grid ---
n_t = 128  # number of FID samples
dt = 1 / 32  # time step -> Nyquist frequency = 1/(2 dt) = 16 Hz
times = np.arange(n_t) * dt

# --- Step 3-4: Estimator returns <X> and <Y> directly (both quadratures in one job) ---
def run_fid(isa_circ, n, est):
    """Complex FID s(t) = sum_i <X_i> + i <Y_i> over the time grid, via the Estimator."""
    ox, oy = transverse_obs(n)
    ox = ox.apply_layout(isa_circ.layout)  # map observables onto the transpiled qubits
    oy = oy.apply_layout(isa_circ.layout)
    params = times.reshape(-1, 1)
    res = est.run(
        [(isa_circ, ox, params), (isa_circ, oy, params)]
    ).result()  # both quadratures, one job
    return res[0].data.evs + 1j * res[1].data.evs

def spectrum(fid, T2=1.0):
    sig = fid * np.exp(-times / T2)  # apodization -> Lorentzian linewidth ~ 1/(pi T2)
    spec = np.fft.fftshift(np.fft.fft(sig))
    freq = np.fft.fftshift(np.fft.fftfreq(len(times), dt))
    return freq, np.abs(spec)

Extensie: un sistem AX2_22​ și regula n+1n+1n+1​

Adăugăm acum un al doilea vecin echivalent. Într-un sistem AX2_22​, un spin A se cuplează, cu același JJJ, cu doi spini X echivalenți. (Reține că X este doar o etichetă pentru cele două spinuri echivalente; nu are legătură cu operatorii Pauli XXX. Fiecare cuplaj de mai jos este tot ZZZZZZ.) Spinul A vede atunci patru configurații ale vecinilor (↑↑, ↑↓, ↓↑, ↓↓)(\uparrow\uparrow,\ \uparrow\downarrow,\ \downarrow\uparrow,\ \downarrow\downarrow)(↑↑, ↑↓, ↓↑, ↓↓); cele două mixte coincid, deci A este despicat într-un triplet 1:2:1 (n=2⇒n+1=3n=2 \Rightarrow n+1 = 3n=2⇒n+1=3 linii). Fiecare spin X vede doar A și rămâne dublet. Spinurile echivalente nu se despică unele pe altele, deci nu includem niciun cuplaj X–X.

O moleculă reală cu acest model este 1,1,2-tricloroetanul (Cl2_22​CH–CH2_22​Cl). Când țintim spinurile hidrogenului (cea mai comună formă de RMN), singurul proton de hidrogen din CH joacă rolul lui A, iar cei doi protoni echivalenți CH2_22​ sunt cei doi spini X. Acum numără pur și simplu vecinii: protonul CH are doi vecini (perechea CH2_22​), deci semnalul său se despică într-un triplet 1:2:1 (n=2n=2n=2); fiecare proton CH2_22​ are doar un vecin (CH-ul), deci semnalul CH2_22​ este un dublet 1:1 (n=1n=1n=1). Observă că grupul cu mai puțini protoni (CH) arată mai multe linii; numărul de linii reflectă câți vecini are un semnal, nu câți protoni îl împart.

Mai jos simulăm un sistem AX2_22​ cu trei qubiți.

În spectrul AX, cele două dublete sunt separate (centru la centru) cu 12 Hz, iar cele două linii din fiecare dublet sunt la 2 Hz distanță. Care număr este diferența de deplasare chimică și care este constanta de cuplaj JJJ? Dacă ai trece la un spectrometru cu un câmp magnetic de două ori mai mare, care dintre ele s-ar schimba?

Răspuns

Separarea de 12 Hz de la centru la centru este diferența de deplasare chimică (ν1−ν2\nu_1-\nu_2ν1​−ν2​); distanța de 2 Hz dintre linii este constanta de cuplaj JJJ. Deplasările chimice provin din ecranarea lui B0B_0B0​, deci scalează cu câmpul. La un câmp dublu, separarea se dublează la 24 Hz. Cuplajul JJJ este o proprietate moleculară prin legături și nu depinde de câmp, deci rămâne 2 Hz. Chimiștii deosebesc deplasarea de cuplaj urmărind cum scalează o despicare cu câmpul.

Răspuns

Cu n=3n=3n=3 vecini echivalenți, A devine un cvartet 1:3:3:1. Spinurile echivalente nu se despică unele pe altele deoarece cuplajul lor deplasează nivelurile de energie relevante toate cu aceeași cantitate, astfel încât diferențele dintre aceste niveluri — frecvențele pe care le vedem — nu se schimbă.

Concluzie​

Am folosit un computer cuantic real pentru a explora cum execută precesie și se decoerează spinurile nucleare într-un experiment RMN și cum să interpretăm spectrele rezultate. Merită să facem un pas înapoi pentru a revedea de ce a fost posibil acest lucru și de ce este mai mult decât o curiozitate.

Un qubit și un nucleu cu spin 1/2 sunt, matematic, același obiect: sisteme cuantice cu două niveluri aflate pe sfera Bloch, rotite de pulsuri rezonante, executând precesie în jurul unei axe și pierzând coerența în favoarea mediului. Întregul vocabular al acestui modul (frecvența Larmor, sistemul de referință rotitor, T1T_1T1​, T2T_2T2​ și T2∗T_2^*T2∗​, franjele Ramsey, ecoul Hahn) aparține în egală măsură RMN-ului și calculului cuantic. Ceea ce un chimist numește deplasare chimică, un inginer cuantic numește rotație ZZZ pe un singur qubit; ceea ce un chimist numește cuplaj JJJ, un inginer cuantic numește interacțiune ZZZZZZ. Cele două domenii au descris aceeași fizică în cuvinte diferite.

Această legătură este istorică, nu doar conceptuală: RMN-ul a fost una dintre primele platforme care au rulat algoritmi cuantici reali. Până în 2001, o moleculă în soluție executase algoritmul lui Shor pentru a factoriza 15, fiecare spin nuclear servind drept qubit. RMN-ul a oferit calculului cuantic și o mare parte din setul său de instrumente de control. Ecoul de spin, trenurile de pulsuri CPMG, pulsurile compuse și decuplarea dinamică au fost toate inventate de spectroscopiști cu zeci de ani înainte ca qubiții să aibă nevoie de ele pentru a combate decoerența. Există o simetrie satisfăcătoare în ceea ce tocmai am făcut: domeniul care a dat naștere primelor computere cuantice este acum ceva ce un computer cuantic poate simula.

Recapitulare și întrebări​

Concepte esențiale​

  • Un qubit este un sistem cu două niveluri creat artificial, echivalent cu un spin 1/2; ∣0⟩/∣1⟩|0\rangle/|1\rangle∣0⟩/∣1⟩, frecvența, porțile, T1T_1T1​ și T2T_2T2​ sunt analoagele directe ale mărimilor din RMN.

  • Un puls rezonant rotește vectorul Bloch; unghiul de basculare stabilește rotația, iar curba Rabi/de nutație P1=sin⁡2(θ/2)P_1=\sin^2(\theta/2)P1​=sin2(θ/2) identifică rotațiile π\piπ și π/2\pi/2π/2.

  • T1T_1T1​ este relaxarea energiei (spin-rețea); T2T_2T2​ este relaxarea fazei (spin-spin); T2∗T_2^{*}T2∗​ include în plus defazarea statică reversibilă pe care un ecou Hahn o refocalizează.

  • O moleculă este un set de spinuri cuplate: deplasarea chimică stabilește poziția fiecărui vârf, iar cuplajul JJJ împarte vârfurile în multipleți după regula n+1n+1n+1, care împreună codifică mediul chimic și conectivitatea.

Adevărat / fals​

  1. A/F Frecvența Larmor este diferența de energie dintre cele două stări de spin împărțită la ℏ\hbarℏ.

  2. A/F Un puls de 90∘90^\circ90∘ (π/2\pi/2π/2) inversează complet un spin aflat la echilibru.

  3. A/F T2∗T_2^{*}T2∗​ este în general mai lung decât T2T_2T2​.

  4. A/F Ecoul Hahn refocalizează defazarea spin-spin ireversibilă.

  5. A/F Într-un sistem AX2_22​, nucleul A apare ca un triplet 1:2:1.

  6. A/F Constanta de cuplaj JJJ se dublează când dublezi câmpul magnetic al spectrometrului.

  7. A/F Eliminarea Qiskit Pulse face imposibilă măsurarea lui T1T_1T1​ pe hardware-ul actual.

Anexă (opțional): evoluție Trotterizată — lasă decoerența să stabilească lățimea liniei​

În secțiunea Spectroscopia RMN a unei molecule, evoluția e−iHte^{-iHt}e−iHt este aplicată într-un singur strat a cărui adâncime nu crește cu ttt, deci FID-ul nu scade de la sine și impunem lățimea liniei cu fereastra de apodizare e−t/T2e^{-t/T_2}e−t/T2​. Această celulă opțională adoptă abordarea opusă. Ea împarte evoluția în ppp pași Trotter și pune o barieră după fiecare pas (astfel încât transpiler-ul să nu-i poată îmbina înapoi într-un singur strat). Punctul de timp kkk folosește kkk pași, deci adâncimea circuitului crește cu timpul.

Deoarece toți termenii din HHH comută, aceasta este exactă: pe un simulator fără zgomot dă aceleași vârfuri înguste. Dar pe un backend cu model de zgomot sau pe hardware real, eroarea acumulată a porților face FID-ul să scadă de la sine, iar această descreștere este cea care stabilește lățimea liniei. Aceasta este ideea T2↔T_2\leftrightarrowT2​↔lățimea liniei din secțiunea experimentul T2T_2T2​, T2∗T_2^*T2∗​, apărând acum din decoerență reală în loc de o fereastră de procesare. Rulăm în acest mod atât sistemul AX (două dublete), cât și sistemul AX2_22​ (un triplet 1:2:1 plus un dublet).

Două note practice de luat în considerare. În primul rând, costul este adâncimea: cel mai adânc circuit AX folosește ∼ ⁣47\sim\!47∼47 de porți pe doi qubiți, iar versiunea AX2_22​ aproximativ dublu, deci ambele sunt mult mai zgomotoase și mai costisitoare decât versiunea exactă. În al doilea rând, fiecare sistem de spin este tot trimis ca un singur job, iar fiecare punct de timp reutilizează aceeași dispunere a qubiților fizici selectată în secțiunea de spectroscopie. Dacă USE_BATCH=True, aceste joburi folosesc și Batch-ul opțional valabil pentru tot notebook-ul.

# Trotterized FID: depth grows with time, so real decoherence (not apodization) sets the linewidth.
estimator.options.default_shots = 2000  # deep circuits need more shots in this appendix
n_tr, dt_tr = (
    48,
    1 / 20,
)  # Nyquist = 1/(2 dt) = 10 Hz (covers the AX2 triplet's 8 Hz line)
times_tr = np.arange(n_tr) * dt_tr
APODIZE_TROTTER = False  # keep False so the linewidth comes from decoherence

def trotter_fid_circuit(offsets, couplings, p, step):
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # 90-degree pulse
    for _ in range(p):  # p Trotter steps, each of duration `step`
        for i, nu in enumerate(offsets):
            qc.rz(2 * np.pi * nu * step, i)  # chemical-shift evolution for one step
        for (i, j), J in couplings.items():
            qc.rzz(np.pi * J * step, i, j)  # J-coupling evolution for one step
        qc.barrier()  # <-- stops the transpiler merging the steps
    return qc

def run_trotter(offsets, couplings, n, est, pass_manager):
    # Time point k uses k Trotter steps (its own circuit). Submit every time point and both
    # quadratures together as ONE Estimator job, using one fixed physical-qubit layout.
    ox, oy = transverse_obs(n)
    pubs = []
    for k in range(n_tr):
        isa = pass_manager.run(trotter_fid_circuit(offsets, couplings, k, dt_tr))
        pubs.append((isa, ox.apply_layout(isa.layout)))  # <X> at time k
        pubs.append((isa, oy.apply_layout(isa.layout)))  # <Y> at time k
    res = est.run(pubs).result()
    return np.array(
        [res[2 * k].data.evs + 1j * res[2 * k + 1].data.evs for k in range(n_tr)]
    )

def trotter_spectrum(fid):
    sig = fid * np.exp(-times_tr / 1.0) if APODIZE_TROTTER else fid
    spec = np.abs(np.fft.fftshift(np.fft.fft(sig)))
    freq = np.fft.fftshift(np.fft.fftfreq(n_tr, dt_tr))
    return freq, spec

fid_tr = run_trotter(
    ax_offsets, ax_couplings, 2, estimator, pm_ax
)  # AX  -> two doublets
fid2_tr = run_trotter(
    ax2_offsets, ax2_couplings, 3, estimator, pm_ax2
)  # AX2 -> triplet + doublet

f_ax, s_ax = trotter_spectrum(fid_tr)
f_ax2, s_ax2 = trotter_spectrum(fid2_tr)

ax[0].plot(times_tr, np.abs(fid2_tr), "s-", label="AX$_2$")

ax[0].set_title("Trotter FID envelope (decays only on a noisy backend)")

ax[1].set_xlim(-12, 12)
ax[1].set_xlabel(r"frequency $\nu$ (Hz)")
ax[1].set_ylabel("intensity")
