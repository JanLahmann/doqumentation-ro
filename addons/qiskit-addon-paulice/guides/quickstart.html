Pornire rapidă

Acest ghid prezintă un exemplu funcțional minimal al pachetului qiskit-paulice. Folosim verificări Pauli spațiu-timp pentru a detecta erorile în timpul execuției unui circuit Clifford, apoi postselectăm doar eșantioanele pentru care nu a fost detectată nicio eroare. Pentru un flux de lucru complet, mai explicativ, care cuantifică îmbunătățirea fidelității, consultă tutorialul detaliat.

Pașii fluxului de lucru

  1. Pregătește intrările: un circuit Clifford de încărcare utilă, qubiții țintă/auxiliari care vor găzdui verificările și un model de zgomot.
  2. Găsește verificări Pauli spațiu-timp potrivite și adaugă-le la circuit.
  3. Eșantionează circuitul verificat.
  4. Postselectează doar eșantioanele pentru care nu a fost detectată nicio eroare.

1. Pregătește intrările​

add_pauli_checks primește un circuit Clifford care se termină cu măsurători (sau, cu argumentul stabilizers, unul fără măsurători, ca în ghidul codurilor spațiu-timp), qubiții țintă care vor fi folosiți pentru a implementa verificările și un model de zgomot folosit pentru a evalua verificările candidate. Aici construim un circuit Clifford aleatoriu de adâncime mică, îl așezăm pe un lanț 1D de qubiți fizici de pe ibm_boston, asociem fiecare qubit al încărcăturii utile cu un qubit auxiliar vecin (astfel încât o verificare să nu necesite porți SWAP) și deducem un model aproximativ de zgomot depolarizant din datele de benchmark ale backendului.

# Added by doQumentation — installs the packages this notebook needs if they are missing
import importlib.util

_needed = {"numpy": "numpy", "qiskit": "qiskit", "qiskit_aer": "qiskit-aer", "qiskit_ibm_runtime": "qiskit-ibm-runtime", "qiskit_paulice": "qiskit-paulice"}
_missing = [pip for module, pip in _needed.items()
            if importlib.util.find_spec(module) is None]
# One at a time, so a package that fails to install does not block the others
for _pip in _missing:
    %pip install -q {_pip}
if not _missing:
    print("\u2713 All required packages are installed")
import numpy as np
from qiskit import QuantumCircuit
from qiskit_ibm_runtime import QiskitRuntimeService
from qiskit_paulice.layout import get_check_qubits
from qiskit_paulice.noise_models import NoiseModel

# Backend and a 1D chain of physical qubits to run on
backend = QiskitRuntimeService().backend("ibm_boston")
layout = [68, 69, 78, 89, 90, 91, 98, 111, 112, 113, 119, 133]

# A shallow brickwork random Clifford payload circuit
rng = np.random.default_rng(1764)
circuit = QuantumCircuit(len(layout))
circuit.h(range(circuit.num_qubits))
for d in range(4):
    for i in range(d % 2, circuit.num_qubits - 1, 2):
        circuit.cz(i, i + 1)
    for q in range(circuit.num_qubits):
        if rng.integers(0, 2):
            circuit.sx(q)
        if rng.integers(0, 2):
            circuit.s(q)
circuit.measure_all()

# Pair each payload qubit with a neighboring ancilla to host a check (no SWAPs needed)
target_qubits, ancilla_qubits = get_check_qubits(backend.coupling_map, layout)

# A rough depolarizing noise model from backend benchmark data, used to score checks
noise_model = NoiseModel.from_backend(
    backend, layout, uniform_gate_noise=True
)

circuit.draw("mpl", fold=-1)

2. Găsește și adaugă verificări Pauli spațiu-timp​

add_pauli_checks caută verificări eficiente, cu pondere mică, pentru fiecare qubit țintă și le adaugă la circuit, returnând o secvență de instanțe CheckedCircuit. Instanțele CheckedCircuit conțin un număr crescător de verificări, de la 0 verificări până la o verificare pentru fiecare qubit țintă. Fiecare verificare îmbunătățește capacitatea de detectare a erorilor, în schimbul unei adâncimi ușor mărite a circuitului. Pentru acest exemplu vom folosi circuitul cu o verificare pe fiecare qubit țintă.

from qiskit_paulice import add_pauli_checks

# The circuit has virtual qubits, so we specify our target qubits with virtual indices
target_qubits_v = [layout.index(q) for q in target_qubits]

# Add spacetime Pauli checks
checked_circuit = add_pauli_checks(circuit, target_qubits_v, noise_model)[-1]
checked_circuit.circuit.draw("mpl", fold=-1, scale=0.4, idle_wires=False)

3. Eșantionează circuitul verificat​

Înainte de eșantionare, transpilăm circuitul verificat pe qubiți fizici (initial_layout = layout + ancilla_qubits) și în setul de porți de bază nativ al ibm_boston. Pentru a emula un QPU zgomotos, eșantionăm cu un backend stabilizator Aer zgomotos, ale cărui rate de eroare corespund noise_model folosit pentru alegerea verificărilor.

from qiskit import transpile
from qiskit_aer import AerSimulator
from qiskit_aer.noise import NoiseModel as AerNoiseModel
from qiskit_aer.noise import ReadoutError, depolarizing_error

# Transpile once: lay the checked circuit out on our qubits and into the native basis
isa_circuit = transpile(
    checked_circuit.circuit,
    backend,
    initial_layout=layout + ancilla_qubits,
    optimization_level=0,
)

# Build an Aer noise model matching the depolarizing model used to pick checks
aer_noise = AerNoiseModel()
aer_noise.add_all_qubit_quantum_error(
    depolarizing_error(noise_model.gate_noise, 2), ["cz"]
)
p = noise_model.readout_noise
aer_noise.add_all_qubit_readout_error(ReadoutError([[1 - p, p], [p, 1 - p]]))
simulator = AerSimulator(method="stabilizer", noise_model=aer_noise)

counts = (
    simulator.run(isa_circuit, shots=1000, seed_simulator=1764)
    .result()
    .get_counts()
)
print(f"sampled {sum(counts.values())} shots")
sampled 1000 shots

4. Postselectează eșantioanele fără eroare detectată​

get_postselection_method asociază fiecare execuție (shot) cu vectorul ei de sindrom; păstrăm doar execuțiile cu sindrom complet nul — cele în care nicio verificare nu a detectat o eroare. Eliminarea execuțiilor semnalate scoate erorile detectate din distribuția rămasă, îmbunătățindu-i fidelitatea, în schimbul unei rate de eșantionare mai mici. Consultă tutorialul pentru o comparație cantitativă a fidelității.

# Keep only the shots in which no check reported an error
ps_fn = checked_circuit.get_postselection_method()
counts_postselected = {
    bs: n for bs, n in counts.items() if not ps_fn(bs).any()
}

kept, total = sum(counts_postselected.values()), sum(counts.values())
print(f"kept {kept} of {total} shots ({kept / total:.0%})")
kept 927 of 1000 shots (93%)
