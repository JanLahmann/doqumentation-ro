Evoluția în timp Trotterizată a modelului Ising 2D cu câmp înclinat cu LTM AI-QEM

Estimare de utilizare: 75 de secunde pe un procesor Heron r2 (LTM AI-QEM: 23 de secunde, ZNE: 52 de secunde). (NOTĂ: Aceasta este doar o estimare. Timpul tău de rulare poate varia.)

Explorează referința API pentru specificații detaliate ale funcției.

Pentru a începe să folosești funcția, urmează ghidul LTM AI-QEM.

Context​

Acest tutorial simulează evoluția în timp Trotterizată a modelului Ising cu câmp înclinat cu funcția LTM AI-QEM.

Conceput inițial pentru a înțelege feromagnetismul și tranzițiile de fază cuantice în materialele magnetice, modelul Ising [1] a devenit o piatră de temelie a fizicii moderne a sistemelor cu multe corpuri. La nivelul său fundamental, modelul descrie o rețea de spini care interacționează, fiecare spin putând ocupa una dintre două stări și interacționând cu vecinii săi cei mai apropiați. Dinamica în timp real a sistemelor Ising bidimensionale devine tot mai greu de simulat clasic pe măsură ce cresc dimensiunea sistemului și timpul de evoluție, ceea ce le face un banc de test important pentru simularea cuantică. În plus, deoarece hamiltonianul este compus din câmpuri locale cu un singur qubit și interacțiuni cu doi qubiți între vecinii cei mai apropiați, evoluția sa în timp poate fi reprezentată în mod natural cu secvențe de porți cuantice cu unul și cu doi qubiți. Aceste proprietăți fac din model un benchmark util pentru studiul dinamicii cuantice pe hardware-ul actual și pentru evaluarea eficienței metodelor de atenuare a erorilor cuantice.

Acest tutorial parcurge următorii pași:

  • Descrie matematic modelul Ising cu câmp înclinat și evoluția sa în timp Trotterizată.

  • Definește backendul și qubiții pe care să simulezi hamiltonianul și vizualizează-i.

  • Definește hamiltonianul Ising cu câmp înclinat cu clasa Qiskit SparsePauliOp.

  • Construiește circuitele cuantice pentru evoluția hamiltonianului cu funcția Qiskit evolved_operator_ansatz.

  • Definește observabila care corespunde magnetizării medii, din nou cu clasa SparsePauliOp.

  • Calculează evoluția magnetizării medii pentru un număr tot mai mare de pași Trotter cu funcția LTM AI-QEM.

  • Aplică metoda extrapolării la zero zgomot (ZNE) rezultatelor brute de pe QPU, pentru a le compara cu atenuarea realizată de funcția LTM AI-QEM.

  • Listează valorile magnetizării medii calculate cu algoritmul dinamicii Pauli rare (SPD), care servesc drept valori ideale.

  • Vizualizează toate rezultatele pentru a compara magnetizarea medie atenuată de LTM AI-QEM cu rezultatele neatenuate, cu rezultatele atenuate de ZNE și cu rezultatele algoritmului SPD clasic.

Modelul Ising cu câmp înclinat și evoluția sa în timp​

Hamiltonianul modelului Ising cu câmp înclinat este următorul:

H=gx∑k∈NXk+gz∑k∈NZk+J∑(k,l)∈Ek<lZkZlH = {g_x}\sum_{k\in{N}}{X_k} + {g_z}\sum_{k\in{N}}{Z_k} + J\sum_{\begin{matrix} {(k,l)}{\in}{E} \\ {k<l} \end{matrix}}{{Z_k}{Z_l}}H=gx​k∈N∑​Xk​+gz​k∈N∑​Zk​+J(k,l)∈Ek<l​∑​Zk​Zl​

unde JJJ este intensitatea cuplajului, iar gxg_xgx​ și gzg_zgz​ sunt intensitățile câmpului transversal, respectiv longitudinal. XkX_kXk​ și ZkZ_kZk​ sunt operatorii Pauli-X și Pauli-Z care acționează asupra qubitului cu indicele kkk. NNN este mulțimea indicilor qubiților care evoluează sub hamiltonian. EEE este mulțimea muchiilor, fiecare dintre ele fiind un tuplu de indici de qubiți (k,l)(k,l)(k,l) între care sunt permise interacțiuni cu doi qubiți. Condiția k<lk<lk<l asigură că nicio interacțiune cu doi qubiți nu se repetă. Pasul 2: Definește hamiltonianul​

Definește hamiltonianul Ising cu clasa Qiskit SparsePauliOp. Pentru aceasta, specifică unghiurile theta_x (θx)(\theta_x)(θx​), theta_z (θz)(\theta_z)(θz​) și theta_zz (θzz)(\theta_{zz})(θzz​), care sunt legate de intensitatea câmpului transversal (g_x), intensitatea câmpului longitudinal (g_z) și, respectiv, intensitatea cuplajului Ising (J). Mai exact, θx=2gxΔt\theta_x=2g_x\Delta{t}θx​=2gx​Δt, θz=2gzΔt\theta_z=2g_z\Delta{t}θz​=2gz​Δt și θzz=2JΔt\theta_{zz}=2J\Delta{t}θzz​=2JΔt.

Folosește metoda SparsePauliOp.from_sparse_list pentru a instanția hamiltonianul câmpului transversal (Hx), hamiltonianul câmpului longitudinal (Hz) și hamiltonianul de cuplaj (Hzz). Metoda SparsePauliOp.from_sparse_list primește ca intrare o listă de tupluri. Fiecare tuplu conține un șir Pauli, indicii qubiților asupra cărora acționează operatorii Pauli din șir și coeficientul șirului Pauli. Pentru mai multe detalii, consultă documentația API SparsePauliOp. Indicii qubiților provin din obiectele problem_nodes și problem_edges definite mai devreme. Hamiltonianul Ising complet cu câmp înclinat este suma acestor trei hamiltoniene.

from qiskit.quantum_info import SparsePauliOp

theta_x = 0.53
theta_z = 0.1
theta_zz = 1.0

g_x = theta_x / 2
g_z = theta_z / 2
J = theta_zz / 2

Hx = SparsePauliOp.from_sparse_list(
    [("X", [node], theta_x / 2) for node in problem_nodes],
    num_qubits=backend_num_nodes,
)
Hz = SparsePauliOp.from_sparse_list(
    [("Z", [node], theta_z / 2) for node in problem_nodes],
    num_qubits=backend_num_nodes,
)
Hzz = SparsePauliOp.from_sparse_list(
    [("ZZ", [i, j], theta_zz / 2) for i, j in problem_edges],
    num_qubits=backend_num_nodes,
)
H = Hx + Hz + Hzz

print(f"Indices of qubits to be evolved(problem_nodes):\n{problem_nodes}\n")

Compararea rezultatelor​

Pentru a compara metodele de atenuare, reprezintă grafic rezultatele LTM AI-QEM, ZNE și ale execuției hardware fără atenuare în raport cu referința SPD, pentru fiecare număr de pași Trotter. Codul afișează și un tabel cu metrici cheie de performanță pentru o comparație cantitativă.

import matplotlib.pyplot as plt
import numpy as np

def compute_improvement_metrics(
    spd_results, mitigated_evs, zne_evs, noisy_evs
):
    """Quantify how much each mitigation method improves on the unmitigated result.

    Error for each method is |SPD - method| at every Trotter step (SPD is ideal).

    Returns a dict keyed by method name with:
      - mae:               mean absolute error vs SPD
      - rmse:              root mean squared error vs SPD
      - mean_improvement:  mean(err_unmitigated - err_method)   (absolute units, >0 is better)
      - pct_improvement:   100 * (MAE_unmitigated - MAE_method) / MAE_unmitigated
      - error_reduction_factor: MAE_unmitigated / MAE_method    (>1 is better)
      - frac_steps_improved:   fraction of steps where the method beats unmitigated
    """
    spd = np.asarray(spd_results, dtype=float)
    errs = {
        "Unmitigated": np.abs(spd - np.asarray(noisy_evs, dtype=float)),
        "ZNE": np.abs(spd - np.asarray(zne_evs, dtype=float)),
        "LTM AI-QEM": np.abs(spd - np.asarray(mitigated_evs, dtype=float)),
    }
    base = errs["Unmitigated"]
    base_mae = base.mean()
    eps = 1e-12

    metrics = {}
    for name, e in errs.items():
        mae = e.mean()
        metrics[name] = {
            "mae": mae,
            "rmse": float(np.sqrt(np.mean(e**2))),
            "mean_improvement": float((base - e).mean()),
            "pct_improvement": float(
                100 * (base_mae - mae) / max(base_mae, eps)
            ),
            "error_reduction_factor": float(base_mae / max(mae, eps)),
        }
    return metrics

def plot_trotter_results(
    trotter_steps,
    spd_results,
    mitigated_evs,
    mitigated_errs,
    zne_evs,
    zne_errs,
    noisy_evs,
    noisy_errs,
    title="",
    print_summary=True,
):
    """Plot magnetization versus Trotter steps, and the absolute difference from SPD for each method.

    Top: average magnetization for each method.
    Bottom: grouped bars of |SPD - method|, with mean improvement annotated.

    Returns a dict of improvement metrics (see compute_improvement_metrics).
    """
    spd = np.asarray(spd_results)
    steps = np.asarray(trotter_steps)

    metrics = compute_improvement_metrics(
        spd_results, mitigated_evs, zne_evs, noisy_evs
    )

    series = [
        (spd_results, None, "Sparse Pauli Dynamics", "*", "green"),
        (
            mitigated_evs,
            mitigated_errs,
            "Mitigation by LTM AI-QEM",
            "P",
            "royalblue",
        ),
        (zne_evs, zne_errs, "Mitigation by ZNE", "^", "darkorange"),
        (noisy_evs, noisy_errs, "Unmitigated", "X", "red"),
    ]

    fig, (ax1, ax2) = plt.subplots(
        nrows=2, ncols=1, figsize=(12, 10), sharex=True, height_ratios=[2, 1]
    )

    for values, errs, label, marker, color in series:
        ax1.errorbar(
            steps,
            values,
            yerr=errs,
            label=label,
            marker=marker,
            color=color,
            markeredgecolor="black",
            markeredgewidth=0.5,
            ecolor="black",
            capsize=5,
        )

    ax1.set_ylabel("Average Magnetization")
    ax1.set_title(title)
    ax1.grid(alpha=0.3)
    ax1.legend()

    # Bottom: grouped bars with MAE and % improvement in the legend labels
    bars = [
        (mitigated_evs, "LTM AI-QEM", "royalblue"),
        (zne_evs, "ZNE", "darkorange"),
        (noisy_evs, "Unmitigated", "red"),
    ]
    n = len(bars)
    width = 0.8 / n
    for i, (values, key, color) in enumerate(bars):
        offset = (i - (n - 1) / 2) * width
        m = metrics[key]
        if key == "Unmitigated":
            label = f"|SPD - {key}| (MAE={m['mae']:.3f})"
        else:
            label = (
                f"|SPD - {key}| (MAE={m['mae']:.3f}, "
                f"{m['pct_improvement']:+.1f}% vs unmitigated)"
            )
        ax2.bar(
            steps + offset,
            np.abs(spd - np.asarray(values)),
            width=width,
            label=label,
            color=color,
            edgecolor="black",
            linewidth=0.5,
        )
        if key != "Unmitigated":
            pass
        ax2.axhline(
            m["mae"], color=color, linestyle="--", linewidth=1, alpha=0.8
        )

    ax2.set_xticks(steps)
    ax2.set_xlabel("Trotter Steps")
    ax2.set_ylabel("|SPD - method|")
    ax2.set_title(
        "Difference from SPD (closer to 0 is better; dashed = mean error)"
    )
    ax2.grid(alpha=0.3, axis="y")
    ax2.legend()

    fig.tight_layout()
    plt.show()

    if print_summary:
        print(
            f"{'Method':<12}{'MAE':>10}{'RMSE':>10}{'Mean impr.':>12}"
            f"{'% impr.':>10}{'Factor':>9}"
        )
        for name, m in metrics.items():
            print(
                f"{name:<12}{m['mae']:>10.4f}{m['rmse']:>10.4f}"
                f"{m['mean_improvement']:>12.4f}{m['pct_improvement']:>9.1f}%"
                f"{m['error_reduction_factor']:>9.2f}"
            )

    return None
plot_trotter_results(

    mitigated_stds,

    zne_stds,
    noisy_evs,
    noisy_stds,
)
