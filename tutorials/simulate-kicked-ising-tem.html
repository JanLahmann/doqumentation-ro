Simularea modelului Ising cu kick folosind funcția TEM

Metoda Tensor-network Error Mitigation (TEM) de la Algorithmiq este un algoritm hibrid cuantic-clasic care elimină complet efectul zgomotului hardware în post-procesarea clasică. Circuitul rulează pe QPU așa cum este scris, cu o măsurătoare informațional completă (IC) la final. Apoi se aplică rezultatelor măsurătorilor o rețea de tensori care inversează zgomotul învățat al dispozitivului, obținându-se valori de așteptare cu erori atenuate.

Acest tutorial reproduce, la 31 de qubiți, tipul de experiment de dinamică a sistemelor cu mulți corpuri rulat pe până la 91 de qubiți în L. E. Fischer et al., Nat. Phys. (2026). El arată:

  • Cât din semnal distruge zgomotul hardware într-un circuit de dinamică la scară de utilitate și cât recuperează TEM.

  • Cum se compară TEM cu probabilistic error cancellation (PEC) și zero-noise extrapolation (ZNE) pe același circuit.

Măsurătoarea IC face posibilă și estimarea observabilelor care nu au fost solicitate când a rulat circuitul, printr-o nouă rulare doar a post-procesării clasice. Pentru un exemplu care estimează întregul con de lumină al unui lanț, consultă Rularea 4: măsoară conul de lumină din aceleași date.

Pentru a regla acuratețea TEM în raport cu costul său QPU și clasic, consultă exemplul însoțitor Reglează funcția TEM pentru acuratețe și cost.

Estimare de utilizare: aproximativ 20 de secunde QPU pentru TEM pe ibm_phoenix (timpul QPU depinde puternic de dispozitivul ales). Comparația opțională PEC și ZNE durează cu aproximativ 35 de minute QPU în plus, aproape tot pentru PEC.

Context: lanțul Ising kicked​

Modelul Ising kicked alternează o evoluție Ising pe un lanț de NNN qubiți,

H^I=J∑n=0N−2Z^nZ^n+1+h∑n=0N−1Z^n,\hat{H}_{\text{I}} = J \sum_{n=0}^{N-2} \hat{Z}_n \hat{Z}_{n+1} + h \sum_{n=0}^{N-1} \hat{Z}_n ,H^I​=J∑n=0N−2​Z^n​Z^n+1​+h∑n=0N−1​Z^n​,

cu un kick transversal,

H^K=b∑n=0N−1X^n.\hat{H}_{K} = b \sum_{n=0}^{N-1} \hat{X}_n .H^K​=b∑n=0N−1​X^n​.

O perioadă a dinamicii este operatorul unitar Floquet U^KI=e−iH^Ke−iH^I\hat{U}_{\text{KI}} = e^{-i \hat{H}_K} e^{-i \hat{H}_I}U^KI​=e−iH^K​e−iH^I​. Pe un computer cuantic, fiecare perioadă este un brickwork de rotații ZZZZZZ cu doi qubiți urmate de rotații cu un singur qubit, deci circuitul conține doar două straturi distincte de porți cu doi qubiți, repetate.

Mărimea de interes este funcția de autocorelație la temperatură infinită a primului spin. Lucrarea de referință arată că aceasta poate fi măsurată pregătind primul qubit în ∣+⟩|+\rangle∣+⟩ și fiecare altă pereche de qubiți în starea Bell (∣00⟩+∣11⟩)/2(|00\rangle + |11\rangle)/\sqrt{2}(∣00⟩+∣11⟩)/2​, evoluând timp de ttt perioade și măsurând un operator Pauli cu un singur qubit X^n\hat{X}_nX^n​.

În punctul unitar dual ∣J∣=∣b∣=π/4|J| = |b| = \pi/4∣J∣=∣b∣=π/4 modelul este exact rezolvabil:

  • Corelația se propagă de-a lungul lanțului cu viteză maximă, deci după ttt perioade doar qubitul n=tn = tn=t o poartă, iar ⟨X^n≠t⟩=0\langle \hat{X}_{n \neq t} \rangle = 0⟨X^n=t​⟩=0.

  • Pe acel qubit, ⟨X^n=t⟩=[cos⁡(2h)]t\langle \hat{X}_{n=t} \rangle = [\cos(2h)]^t⟨X^n=t​⟩=[cos(2h)]t.

Aceste valori exacte fac din model un benchmark riguros pentru atenuarea erorilor: semnalul care ajunge la qubitul ttt a trecut prin fiecare strat al circuitului, deci este expus întregului zgomot al dispozitivului, dar valoarea sa fără zgomot este cunoscută. Departe de punctul unitar dual, aceleași circuite devin greu de simulat clasic, iar aici lucrarea folosește TEM pentru a depăși metodele exacte.

TEM funcționează în trei pași: învață zgomotul fiecărui strat distinct de porți cu doi qubiți și eroarea de citire, rulează circuitul cu o măsurătoare IC și, în final, aplică rețeaua de tensori care inversează zgomotul asupra rezultatelor măsurătorilor pe IBM Cloud®.

Pasul 1: Construiește circuitul și observabilele​

Acest tutorial folosește un circuit care implementează modelul Ising cu kick descris în secțiunea anterioară. Circuitul este pregătit după cum urmează. În primul rând, există o fază de pregătire a stării, în care primul qubit se află în starea ∣+⟩|+\rangle∣+⟩, în timp ce ceilalți sunt în perechi Bell (∣00⟩+∣11⟩)/2(|00\rangle + |11\rangle)/\sqrt{2}(∣00⟩+∣11⟩)/2​. Aceasta este urmată de structura de tip cărămidă care implementează evoluția unitară U^KI\hat{U}_{\text{KI}}U^KI​. Numărul de pași temporali fizici corespunde la t/2t/2t/2 straturi de circuit. Codul următor construiește circuitul folosit în acest tutorial.

from qiskit import QuantumCircuit

def kicked_ising_circuit(n_qubits, t_steps):
    """Kicked Ising circuit at the dual unitary point (J = b = pi/4, h = 0)."""
    circuit = QuantumCircuit(n_qubits)

    # State preparation: |+> on qubit 0, Bell pairs on (1, 2), (3, 4), ...
    circuit.h(0)
    for i in range(1, n_qubits - 1, 2):
        circuit.h(i)
        circuit.x(i + 1)
        circuit.cx(i, i + 1)
    circuit.barrier()

    # Clifford two-qubit block: one ZZ rotation, X kick, one ZZ rotation
    block = QuantumCircuit(2)
    block.sdg([0, 1])
    block.cx(0, 1)
    block.sdg(0)
    block.h([0, 1])
    block.s(1)
    block.cx(0, 1)
    block.s(0)
    block.h(0)
    block.sdg(0)
    block.y(1)
    block.h(1)

    # Brickwork: even periods act on (0, 1), (2, 3), ...; odd periods on (1, 2), (3, 4), ...
    for step in range(t_steps):
        for q in range(step % 2, n_qubits - 1, 2):
            circuit.compose(block, [q, q + 1], inplace=True)
        circuit.barrier()
    return circuit

Apoi, construiește observabilul X^n=t\hat{X}_{n=t}X^n=t​. Acesta este construit ca un șir Pauli simplu cu ordinea corespunzătoare celei utilizate de Qiskit:

def xt_observable(n_qubits, t_steps):
    pauli_str = "".join(["I" * t_steps, "X", "I" * (n_qubits - t_steps - 1)])
    pauli_str = pauli_str[::-1]  # Reverse the string to match qiskit order
    return SparsePauliOp(data=pauli_str, coeffs=1.0)

Experimentul folosește 31 de qubiți și 15 perioade la h=0h = 0h=0, deci valoarea exactă a lui ⟨X^n=15⟩\langle \hat{X}_{n=15} \rangle⟨X^n=15​⟩ este 1. Acesta este un circuit la scară de utilitate cu 465 de porți cu doi qubiți: 15 care pregătesc perechile Bell și 30 în fiecare perioadă. Semnalul care ajunge la qubitul 15 trece prin sute dintre ele.

Apoi, obține acces la funcția TEM și selectează un backend dintre dispozitivele disponibile. Acest cod presupune că ți-ai salvat deja contul în mediul tău local.

Transpilează circuitul pentru dispozitivul ales o singură dată și mapează observabila pe qubiții pe care a fost plasat. TEM acceptă acest circuit instruction set architecture (ISA) ca atare, iar comparația PEC și ZNE din Pasul 3 folosește același circuit, astfel încât toate metodele rulează aceleași porți pe aceiași qubiți.

from qiskit.transpiler import generate_preset_pass_manager
from qiskit_ibm_runtime import QiskitRuntimeService

service = QiskitRuntimeService()
backend = service.backend(backend_name)

pass_manager = generate_preset_pass_manager(
    optimization_level=3, backend=backend
)
isa_circuit = pass_manager.run(circuit)
isa_observable = observable.apply_layout(isa_circuit.layout)

# Collect the input PUBs, in this case composed of a single circuit and observable

Opțiunile următoare se bazează pe fizica circuitului:

  • max_layers_to_learn: 4: o limită superioară a numărului de straturi distincte de porți pe doi qubiți al căror zgomot este învățat. Structura brickwork are doar două straturi distincte, deci doar acestea două sunt învățate.

  • default_shots: 100_000: numărul de shot-uri al măsurării IC, care stabilește precizia statistică a estimării.

  • tem_max_bond_dimension: 128 și tem_compression_cutoff: 1e-14: o dimensiune de legătură moderată, care menține rapidă post-procesarea clasică la 31 de qubiți, cu un prag mic, astfel încât dimensiunea de legătură să nu fie trunchiată în continuare.

  • private: False: păstrează rezultatele jobului descărcabile ulterior. Setează-l la True pentru circuite confidențiale.

Exemplul de ajustare a performanței explică în detaliu fiecare dintre aceste opțiuni.

Calculează dimensiunea funcției de care are nevoie jobul cu ajutorul calculatorului de dimensiuni furnizat de IBM® și transmite-o lui tem.run ca function_size. Calculatorul mapează circuitul pe Backend și returnează S, M sau L fără a trimite nimic; vezi Function sizes.

# Calculate the function size a circuit needs, before submitting it.
#
# Call ``calculate_function_size(pubs, backend)``: it returns "S", "M" or "L" and submits
# nothing. Pass the whole list of PUBs -- a job runs at one size, and the heaviest PUB
# decides it. The circuit is measured after being mapped onto ``backend``, since mapping
# can add both qubits and depth.

from collections.abc import Iterable
from typing import Any, Literal

from qiskit.circuit import Barrier
from qiskit.circuit.equivalence_library import SessionEquivalenceLibrary
from qiskit.transpiler import PassManager
from qiskit.transpiler.passes import (
    ApplyLayout,
    BarrierBeforeFinalMeasurements,
    BasisTranslator,
    EnlargeWithAncilla,
    FilterOpNodes,
    FullAncillaAllocation,
    HighLevelSynthesis,
    SabreSwap,
    TrivialLayout,
    UnitarySynthesis,
)

Size = Literal["S", "M", "L"]
_ORDER = {"S": 0, "M": 1, "L": 2}

# Limits are provided by IBM
_SMALL_QUBITS, _SMALL_DEPTH_2Q = 40, 40
_MEDIUM_QUBITS, _MEDIUM_DEPTH_2Q = 100, 100

# Any fixed value works; what matters is that it does not change between calls.
_SEED_TRANSPILER = 42

# Added by BarrierBeforeFinalMeasurements so routing cannot move gates past a measurement,
# then removed again once routing is done.
_PROTECTION_BARRIER = "qiskit.transpiler.internal.routing.protection.barrier"

def calculate_function_size(
    circuit: QuantumCircuit | Iterable[Any], backend, **kwargs: Any
) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    circuits = pub_circuits(circuit)
    if not circuits:
        raise ValueError(
            "No circuit to size: pass a QuantumCircuit or a non-empty list of PUBs."
        )
    return max(
        (_calculate_circuit_size(qc, backend, **kwargs) for qc in circuits),
        key=_ORDER.__getitem__,
    )

def _calculate_circuit_size(
    circuit: QuantumCircuit, backend, **kwargs: Any
) -> Size:
    """Return the size required to run a single circuit."""
    metrics = _measure(circuit, backend, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def pub_circuits(problem: Any) -> list[QuantumCircuit]:
    """Return the circuits in ``problem``: one circuit, or one per PUB in a list."""
    if isinstance(problem, QuantumCircuit):
        return [problem]
    circuits: list[QuantumCircuit] = []
    for index, pub in enumerate(problem):
        if isinstance(pub, QuantumCircuit):
            circuit = pub
        elif isinstance(getattr(pub, "circuit", None), QuantumCircuit):
            circuit = pub.circuit
        elif (
            isinstance(pub, (tuple, list))
            and pub
            and isinstance(pub[0], QuantumCircuit)
        ):
            circuit = pub[0]
        else:
            raise ValueError(f"PUB #{index} has no QuantumCircuit to size.")
        circuits.append(circuit)
    return circuits

def _pass_manager(target) -> PassManager:
    """Return the pass manager used to map a circuit onto ``target``.

    Fixed and seeded, so the same circuit always gives the same size.
    """
    basis = list(target.operation_names)
    library = SessionEquivalenceLibrary
    return PassManager(
        [
            UnitarySynthesis(
                basis, approximation_degree=1.0, min_qubits=3, target=target
            ),
            HighLevelSynthesis(
                target=target,
                equivalence_library=library,
                basis_gates=basis,
                min_qubits=3,
            ),
            BasisTranslator(library, basis, target=target, min_qubits=3),
            TrivialLayout(target),
            FullAncillaAllocation(target),
            EnlargeWithAncilla(),
            ApplyLayout(),
            BarrierBeforeFinalMeasurements(label=_PROTECTION_BARRIER),
            SabreSwap(
                target, heuristic="basic", seed=_SEED_TRANSPILER, trials=5
            ),
            FilterOpNodes(lambda node: node.label != _PROTECTION_BARRIER),
            UnitarySynthesis(basis, approximation_degree=1.0, target=target),
            HighLevelSynthesis(
                target=target,
                equivalence_library=library,
                basis_gates=basis,
                use_qubit_indices=True,
            ),
            BasisTranslator(library, basis, target=target),
        ]
    )

def _count(isa: QuantumCircuit) -> dict:
    """Return the active qubits and two-qubit-gate depth of a mapped circuit."""
    active = {
        q
        for instr in isa.data
        if not isinstance(instr.operation, Barrier)
        for q in instr.qubits
    }
    return {
        "num_qubits": len(active),
        "depth_2q": isa.depth(
            filter_function=lambda instr: len(instr.qubits) == 2
            and not isinstance(instr.operation, Barrier)
        ),
    }

def _measure(circuit: QuantumCircuit, backend, **kwargs: Any) -> dict:
    """Map ``circuit`` onto ``backend`` and return its metrics."""
    return _count(_pass_manager(backend.target).run(circuit))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return (
        metrics["num_qubits"] <= _SMALL_QUBITS
        and metrics["depth_2q"] <= _SMALL_DEPTH_2Q
    )

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return (
        metrics["num_qubits"] <= _MEDIUM_QUBITS
        and metrics["depth_2q"] <= _MEDIUM_DEPTH_2Q
    )
size = calculate_function_size(pubs, backend)  # "S", "M" or "L"
print(size)

Pasul 3: Compară cu PEC și ZNE​

Metadatele rezultatului conțin și estimarea nemitigată, calculată din aceleași rezultate de măsurare, fără rețeaua care inversează zgomotul. O comparație a celor două cu valoarea exactă arată cât din semnal distruge zgomotul și cât recuperează TEM: Pentru a pune rezultatul TEM în context, rulează același circuit cu alte două metode de mitigare a erorilor: anularea probabilistică a erorilor (PEC) și extrapolarea la zgomot zero (ZNE) cu amplificare probabilistică a erorilor (PEA).

atenție

unmitigated_stds = metadata_large["stds_wo_tem_wo_qdt"][0]

exact_evs = np.cos(2 * h) ** t_steps

Valoarea nemitigată scade odată cu numărul de porți zgomotoase din conul de lumină al qubitului 15, așa că la această adâncime cea mai mare parte a semnalului se pierde. TEM elimină această scădere în post-procesare, recuperând cea mai mare parte a semnalului fără a rula circuite suplimentare. Diferența rămasă față de valoarea exactă provine din setările orientate spre viteză folosite în acest tutorial: o dimensiune de legătură de 128 și un buget modest de învățare a zgomotului. Exemplul de ajustare a performanței arată cum poți schimba timp QPU și timp clasic pentru acuratețe.
