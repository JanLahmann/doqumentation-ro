Simularea evoluției în timp a modelului Ising cu câmp transversal

Estimare de utilizare: 105 secunde pe un procesor Nighthawk r2 (NOTĂ: Aceasta este doar o estimare. Timpul tău de execuție poate varia.)

Rezultatele învățării​

  1. Învață cum să transpilezi și să rulezi circuite cuantice pe hardware folosind Julia

  2. Învață cum să postprocesezi rezultatele măsurătorilor pentru a calcula valori de așteptare

  3. Învață cum să compari rezultatele de pe hardware cu simularea clasică, pentru a cuantifica efectele combinate ale erorii de aproximare Trotter și ale zgomotului hardware

Cerințe preliminare​

Familiarizează-te cu următoarele subiecte înainte de a începe acest tutorial:

  • Simulare cuantică

  • Modelul Ising cu câmp transversal

  • Introducere în transpilare

Context​

Julia este un limbaj de programare dinamic, conceput în principal pentru calcul numeric și științific. Capacitățile sale de calcul numeric de înaltă performanță îl fac o alegere naturală pentru fluxurile de lucru de simulare cuantică. În acest tutorial, arătăm cum este folosit Julia atât pentru pre- și postprocesarea clasică (de exemplu, construirea Hamiltonienilor, rularea solverelor ODE (ecuații diferențiale ordinare) și calculul valorilor de așteptare), cât și pentru orchestrarea joburilor pe hardware cuantic, eliminând necesitatea de a comuta între limbaje sau medii.

Pentru a interacționa cu hardware-ul IBM Quantum® din Julia, acest tutorial folosește două pachete din ecosistemul Qiskit: Qiskit.jl încapsulează biblioteca C Qiskit și oferă în Julia funcționalități de construire și transpilare a circuitelor; QiskitIBMRuntime.jl se conectează la hardware-ul IBM Quantum prin clientul IBM Quantum Compute Service, permițând trimiterea joburilor și preluarea rezultatelor direct din Julia.

În acest tutorial, considerăm evoluția trotterizată a modelului Ising cu câmp transversal pe un lanț 1D cu interacțiuni între vecinii cei mai apropiați:

H=∑⟨i,j⟩JijZiZj+∑ihiXi H = \sum_{\langle i,j\rangle}J_{ij}Z_iZ_j + \sum_i h_i X_iH=⟨i,j⟩∑​Jij​Zi​Zj​+i∑​hi​Xi​

Pentru a implementa evoluția în timp e−iHτe^{-iH\tau}e−iHτ, împărțim intervalul de timp τ\tauτ în rrr pași și definim Δτ=τ/r\Delta\tau=\tau/rΔτ=τ/r. Descompunerea Trotter-Suzuki de ordinul doi dă următoarea expresie:

e−iHΔτ≈∏ie−ihiXiΔτ/2∏⟨i,j⟩e−iJijZiZjΔτ∏ie−ihiXiΔτ/2 e^{-iH\Delta\tau}\approx \prod_i e^{-ih_i X_i\Delta\tau/2 } \prod_{\langle i,j\rangle} e^{-iJ_{ij}Z_iZ_j\Delta\tau} \prod_i e^{-ih_iX_i\Delta\tau/2}e−iHΔτ≈i∏​e−ihi​Xi​Δτ/2⟨i,j⟩∏​e−iJij​Zi​Zj​Δτi∏​e−ihi​Xi​Δτ/2

Pentru construirea circuitului, fiecare pas Trotter este implementat ca o secvență de rotații RxR_xRx​ pe un singur qubit și de porți RZZR_{ZZ}RZZ​ pe doi qubiți. Circuitul începe prin pregătirea stării Néel ∣0101⋯ ⟩|0101\cdots\rangle∣0101⋯⟩ folosind porți X pe qubiți alternanți. Fiecare pas Trotter următor aplică: (1) Rx(hiΔτ)R_x(h_i\Delta\tau)Rx​(hi​Δτ) pe fiecare qubit, (2) RZZ(2JijΔτ)R_{ZZ}(2J_{ij}\Delta\tau)RZZ​(2Jij​Δτ) pe fiecare pereche vecină de-a lungul lanțului și (3) Rx(hiΔτ)R_x(h_i\Delta\tau)Rx​(hi​Δτ) din nou pe fiecare qubit. Adâncimea totală a circuitului crește liniar cu numărul de pași Trotter rrr.

Exemplu de simulare la scară mică​

Considerăm un lanț 1D de NNN qubiți, descris de modelul Ising cu câmp transversal de mai sus. Pentru sistemul de interes, specificăm mai jos dimensiunea sistemului N, dimensiunea pasului Trotter δt și numărul total de pași Trotter r_max. Timpul total de evoluție este δt * r_max. Reține că Julia acceptă identificatori Unicode precum δt; în notebook sau în Julia REPL, tastează \delta urmat de Tab pentru a introduce δ. Pentru o referință completă, consultă documentația Julia despre introducerea Unicode.

Soluția exactă​

Pentru a stabili o referință față de care să comparăm rezultatele de pe hardware-ul cuantic, demonstrăm mai întâi fluxul de lucru al simulării clasice pentru o problemă la scară mică. Construim hamiltonianul Ising ca matrice rară, apoi obținem evoluția exactă în timp prin integrarea numerică a ecuației Schrödinger folosind ODEProblem din OrdinaryDiffEq.jl. Această abordare scalează exponențial cu numărul de qubiți NNN. Ea necesită stocarea vectorului de stare complet, de dimensiune 2N2^N2N. Pentru N=20N=20N=20, spațiul Hilbert are deja peste un milion de dimensiuni, ceea ce o face impracticabilă pentru sisteme mai mari.

N = 20
δt = 0.05 # Trotter step size
r_max = 10 # total number of Trotter steps

h = fill(1.0, N)
J = fill(1.0, N-1)

# Build the Ising Hamiltonian as a sparse 2^n × 2^n matrix
function build_ising_hamiltonian(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int)
    dim = 2^n

    # diagonal ZZ terms
    diag_terms = zeros(Float64, dim)
    for i in 1:n-1
        for b in 0:dim-1
            bi = bit_at(b, i) # bit at position i
            bi_next = bit_at(b, i+1) # bit at position i + 1
            diag_terms[b+1] += J[i] * (1-2bi) * (1-2bi_next)
        end
    end
    H = spdiagm(0 => complex(diag_terms))

    # off-diagonal local X terms
    for i in 1:n
        mask = 1 << (i-1)
        cols = [xor(b, mask) + 1 for b in 0:dim-1]
        H += h[i] * sparse(1:dim, cols, ones(ComplexF64, dim), dim, dim)
    end
    return H
end

Definim membrul drept al ecuației Schrödinger în forma pe loc schrodinger!(dψ, ψ, H, t), care calculează dψ/dt=−iHψd\psi/dt = -iH\psidψ/dt=−iHψ printr-o înmulțire rară matrice-vector. Apoi configurăm un ODEProblem cu starea Néel drept condiție inițială și îl rezolvăm pe intervalul de timp [0,r⋅δt][0, r \cdot \delta t][0,r⋅δt], salvând starea la fiecare pas de timp δt\delta tδt. Solverul folosit este Tsit5(), o metodă Runge-Kutta explicită standard de ordinul patru/cinci, potrivită pentru probleme non-rigide.

# initial state |0101...01⟩
ψ0 = zeros(ComplexF64, 2^N)
neel_index = sum(1 << (i-1) for i in 1:2:N)
ψ0[neel_index + 1] = 1.0

function schrodinger!(dψ::AbstractVector, ψ::AbstractVector, H::AbstractMatrix, t::Real)
    mul!(dψ, H, ψ)
    dψ .*= -im
end

tspan = (0.0, r_max * δt)
prob = ODEProblem(schrodinger!, ψ0, tspan, H_ising)
sol = solve(prob, Tsit5(), saveat=δt)

function z_expval_from_state(ψ::AbstractVector{<:Complex}, qubit::Int, n::Int)
    s = 0.0
    for b in 0:2^n-1
        bit = bit_at(b, qubit)
        s += (1 - 2bit) * abs2(ψ[b+1])
    end
    return s
end

# Gates to prepare Néel state |0101…⟩, X on every other site
neel_state_gates(n::Int) = [("X", [(i,)]) for i in 1:2:n]

# Gates for one second-order Trotter step of size δt
trotter_step_gates(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int, δt::Real) = vcat(
    [("Rx",  [(i,)],         h[i] * δt) for i in 1:n],
    [("Rzz", [(i,), (i+1,)], 2 * J[i] * δt) for i in 1:n-1],
    [("Rx",  [(i,)],         h[i] * δt) for i in 1:n])

# Make a list of gates: Néel state preparation followed by n_trotter_steps Trotter steps
function make_trotter_circuit_tn(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int, δt::Real,
                                 n_trotter_steps::Int)
    circuit = []

    # Neel state initialization
    append!(circuit, neel_state_gates(n))

    for _ in 1:n_trotter_steps
        append!(circuit, trotter_step_gates(h, J, n, δt))
    end

    return circuit
end

Acum construim circuitul de evoluție în timp trotterizat folosind Qiskit.jl. Circuitul oglindește versiunea cu rețea tensorială: inițializează starea Néel, aplică rrr pași Trotter de porți RxR_xRx​ și RZZR_{ZZ}RZZ​ și, în final, măsoară toți qubiții în baza Z.

function make_trotter_circuit(h::AbstractVector{<:Real}, J::AbstractVector{<:Real}, n::Int, δt::Real, n_trotter_steps::Int)
    qc = QuantumCircuit(n, n)

    # Neel state initialization
    for i in 1:2:n
        x!(qc, i)
    end

    # Trotter evolution
    for _ in 1:n_trotter_steps
        for i in 1:n
            rx!(qc, h[i] * δt, i)
        end

        for i in 1:n-1
            rzz!(qc, 2* J[i] * δt, i, i+1)
        end

        for i in 1:n
            rx!(qc, h[i] * δt, i)
        end
    end

    # measure in Z basis
    for i in 1:n
        measure!(qc, i, i)
    end

function two_qubit_depth(qc::QuantumCircuit)
    qubit_depth = Dict{Int,Int}()
    for inst in qc.data
        length(inst.qubits) == 2 || continue   # skip non-two-qubit gates
        d = maximum(get(qubit_depth, q, 0) for q in inst.qubits)
        for q in inst.qubits
            qubit_depth[q] = d + 1
        end
    end
    return isempty(qubit_depth) ? 0 : maximum(values(qubit_depth))
end

# ⟨M_s⟩ = (1/N) Σ (-1)^i ⟨Z_i⟩, averaged over hardware shots
function staggered_magnetization(samples::AbstractVector{<:AbstractVector}, n::Int)
    s = 0.0
    for sample in samples
        s += sum((-1)^i * (1 - 2 * sample[i]) for i in 1:n) / n
    end
    return s / length(samples)
end

# Calculate the staggered magnetization given a tensor network state
staggered_magnetization(ψ_bpc::BeliefPropagationCache, n::Int) =
    sum((-1)^q * m for (q, m) in enumerate(z_expvals_from_tn_state(ψ_bpc, n))) / n

# Evolve a TN state and record the staggered magnetization at each step.
function compute_staggered_magnetization_tn(δt::Real, nsteps::Int; record_every::Int = 1)
    init_gates = neel_state_gates(N_large)
    step_gates = trotter_step_gates(h_large, J_large, N_large, δt)

    ψ_bpc, fid = apply_gates_to_tn_state(init_gates, tn_initial_state(g_large); apply_kwargs)
    times = [0.0]
    mags = [staggered_magnetization(ψ_bpc, N_large)]
    for k in 1:nsteps
        ψ_bpc, fid_step = apply_gates_to_tn_state(step_gates, ψ_bpc; apply_kwargs)
        fid *= fid_step
        if k % record_every == 0
            push!(times, k * δt)
            push!(mags, staggered_magnetization(ψ_bpc, N_large))
        end
    end
    println("  δt=$(round(δt, digits=5)), $(nsteps) steps: truncation fidelity ≈ $(round(fid, digits=5))")
    (times, mags)
end
