Clasifică riscul de credit cu Rimay Quantum Feature Extraction de la Kipu Quantum

notă

Qiskit Functions sunt o funcționalitate experimentală disponibilă doar utilizatorilor planurilor IBM Quantum® Premium Plan, Flex Plan și On-Prem (prin IBM Quantum Platform API) Plan. Se află în stadiul de versiune preview și pot fi modificate.

Estimare de utilizare: 2 minute pe un procesor Nighthawk r2. (NOTĂ: Aceasta este doar o estimare. Timpul tău de rulare poate varia.)

Obiective de învățare​

  • Pregătește date tabulare cu coloane categorice și numerice pentru Qiskit Function Rimay.

  • Potrivește o mapare cuantică a caracteristicilor pe datele de antrenare și mapează datele de test în aceeași rulare.

  • Antrenează modele clasice pe caracteristici transformate cuantic, singure și combinate cu caracteristicile originale.

  • Compară rezultatele cu o referință pur clasică.

Cerințe preliminare​

Înainte de a începe acest tutorial, ar trebui să fii familiarizat cu următoarele subiecte:

  • Introducere în Qiskit Functions

  • Clasificare supervizată cu scikit-learn

Context​

Multe probleme de învățare automată din industrie implică seturi de date tabulare mici sau medii, în care adăugarea de mai multe date nu este o opțiune, iar acuratețea modelului stagnează. Scorarea riscului de credit este un exemplu tipic. Un creditor folosește câteva zeci de atribute pentru a decide dacă solicitantul va rambursa probabil creditul.

Rimay, o Qiskit Function de la Kipu Quantum, adaugă un pas de preprocesare cuantică într-un astfel de flux de lucru. Implementează algoritmul de extragere cuantică a trăsăturilor cu contradiabaticitate digitizată [1]. Fiecare trăsătură de intrare este mapată pe un qubit. Valorile trăsăturilor și informația mutuală dintre trăsături stabilesc câmpurile locale și cuplajele unui hamiltonian de tip spin-glass. Dinamica contradiabatică face apoi sistemul cuantic să evolueze spre stările sale de energie joasă, iar valorile medii cu unul și cu doi corpuri măsurate la final devin noile trăsături transformate cuantic. Aceste trăsături surprind corelații neliniare între intrări și le poți introduce în orice model clasic.

Acest tutorial folosește setul de date German credit din OpenML [2], cu 1000 de solicitanți și 20 de atribute, pentru a antrena un clasificator random forest. Mai întâi stabilești o referință clasică, apoi trimiți datele către Rimay și, în final, antrenezi același tip de model pe trăsăturile transformate cuantic, singure și combinate cu trăsăturile originale.

Cerințe​

Înainte de a începe acest tutorial, asigură-te că ai instalate următoarele pachete:

  • Clientul IBM Quantum Compute (pip install qiskit-ibm-runtime)

  • Qiskit Functions (pip install qiskit-ibm-catalog)

  • scikit-learn (pip install scikit-learn)

  • pandas (pip install pandas)

  • Matplotlib (pip install matplotlib)

Ai nevoie, de asemenea, de acces la funcția Rimay din Qiskit Functions Catalog.

from sklearn.ensemble import RandomForestClassifier

    accuracy_score,

    recall_score,
    roc_auc_score,
)
from sklearn.model_selection import train_test_split

def train_random_forest(x, y, n_estimators, max_depth):
    """Train a random forest classifier with fixed hyperparameters."""
    model = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        min_samples_split=5,
        min_samples_leaf=1,
        max_features="sqrt",
        random_state=42,
        n_jobs=-1,
    )
    return model.fit(x, y)

def evaluate(model, x, y):
    """Return the classification metrics of a trained model on a test set."""
    y_pred = model.predict(x)
    y_proba = model.predict_proba(x)[:, 1]
    return {
        "Accuracy": accuracy_score(y, y_pred),
        "AUC": roc_auc_score(y, y_proba),
        "F1 score": f1_score(y, y_pred),
        "Precision": precision_score(y, y_pred),
        "Recall": recall_score(y, y_pred),
    }

Pasul 2: Optimizează problema pentru execuția pe hardware cuantic​

Rimay construiește și transpilează circuitele pentru procesorul selectat, deci nu există niciun circuit de optimizat manual. Specifică numărul de shot-uri per circuit, respectând următoarele constrângeri:

  • Fiecare trăsătură necesită un qubit, așa că procesorul trebuie să aibă cel puțin tot atâția qubiți câte trăsături are setul de date.

  • Rimay rulează un circuit pe rând, rândurile de antrenare și de test împreună. Un singur job poate cere cel mult 10 milioane de execuții, deci numărul de rânduri înmulțit cu shots trebuie să rămână în limita acestui buget.

Calculează dimensiunea funcției​

Fiecare job rulează la o dimensiune a funcției, S, M sau L, care selectează resursele de calcul pe care rulează. Pentru Rimay, dimensiunea depinde de numărul de rânduri pe care le mapează un job, rândurile de antrenare și de test împreună. Dacă soliciți o dimensiune prea mică, jobul eșuează cu eroarea 4600. Pentru dimensiuni și limitele lor, vezi Dimensiunile funcției în ghidul Rimay.

Celula următoare definește calculatorul de dimensiune. Rulează pe mașina ta, citește doar datele pe care i le transmiți și nu trimite nimic.

from os import PathLike
from typing import Any, Literal, Sequence, Sized

Size = Literal["S", "M", "L"]

# Upper bounds (inclusive) in samples.
_SMALL = 2_999
_MEDIUM = 9_999

FIT_TRANSFORM, TRANSFORM, DELETE = "fit-transform", "transform", "delete"

# Which positions of input_file hold samples, per mode. The labels in
# y_train submit no circuits of their own, so they are not counted.
SAMPLE_POSITIONS = {FIT_TRANSFORM: (0, 2), TRANSFORM: (0,)}

def calculate_function_size(problem: Sequence[Sized], **kwargs: Any) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    metrics = _measure(problem, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def _measure(problem: Sequence[Sized], **kwargs: Any) -> dict:
    """The samples the job submits."""
    return {"samples": count_samples(problem, kwargs.get("mode"))}

def count_samples(problem: Sequence[Sized], mode: Any) -> int:
    """Rows across the data sets of ``problem`` that carry samples."""
    if mode == DELETE:
        return 0
    if mode not in SAMPLE_POSITIONS:
        raise ValueError(f"cannot size mode {mode!r}")
    if _is_name(problem) or (
        isinstance(problem, (list, tuple))
        and any(_is_name(data) for data in problem)
    ):
        raise TypeError(
            "pass the data, not the file name: read each input_file, e.g. with "
            "pandas.read_csv, and pass the data sets in input_file order"
        )
    if not isinstance(problem, (list, tuple)):
        raise TypeError(
            "pass a list of data sets in input_file order, e.g. [x_train, y_train], "
            f"not a single {type(problem).__name__}"
        )
    return sum(
        len(problem[i]) for i in SAMPLE_POSITIONS[mode] if i < len(problem)
    )

def _is_name(value: Any) -> bool:
    """A file name or path rather than data."""
    return isinstance(value, (str, bytes, PathLike))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return metrics["samples"] <= _SMALL

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return metrics["samples"] <= _MEDIUM

Transmite seturile de date în aceeași ordine ca fișierele din input_file, împreună cu modul rulării:

size = calculate_function_size(
    [x_train, y_train, x_test], mode="fit-transform"
)
print(size)

Rulează Rimay în modul fit-transform. Acesta ajustează o mapare cuantică a trăsăturilor pe x_train.csv și y_train.csv și mapează cu ea atât setul de antrenare, cât și pe cel de test. Ordinea fișierelor din input_file contează. Enumeră trăsăturile de antrenare, etichetele de antrenare și apoi trăsăturile de test opționale. Transmite dimensiunea pe care ai calculat-o ca function_size.

AUC măsoară cât de bine ordonează un model creditele bune înaintea celor rele, independent de un prag de decizie, ceea ce îl face cea mai informativă metrică pentru acest set de date dezechilibrat (70% credite bune). În testele de referință ale Kipu Quantum, trăsăturile transformate cuantic, singure, au atins un AUC similar cu referința clasică, iar modelul hibrid, care le combină pe ambele, a atins cel mai mare AUC și scor F1. Prin urmare, trăsăturile transformate cuantic adaugă informații pe care trăsăturile clasice nu le oferă singure.

Concluzie​

Ce ai realizat​

În acest tutorial ai realizat următoarele:

  1. Ai pregătit un set de date reale de risc de credit, cu atribute categoriale și numerice, pentru extragerea cuantică a trăsăturilor.

  2. Ai stabilit o referință clasică cu random forest.

  3. Ai folosit Rimay pentru a ajusta o mapare cuantică a trăsăturilor pe hardware cuantic și pentru a mapa seturile de antrenare și de test într-o singură rulare.

  4. Ai antrenat același model pe trăsături transformate cuantic și pe trăsături combinate și le-ai comparat cu referința.

Concluzii principale​

  • Rimay se integrează într-un flux de învățare automată existent ca un pas suplimentar de preprocesare. Îți păstrezi pregătirea datelor și modelul clasic.

  • Numărul de qubiți limitează numărul de trăsături de intrare, iar numărul de rânduri înmulțit cu shots limitează dimensiunea unui singur job.

  • Folosește implicit trăsăturile transformate cuantic combinate cu trăsăturile originale, deoarece modelul le poate folosi pe ambele.
