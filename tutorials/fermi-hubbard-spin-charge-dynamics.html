Dinamica spinului și a sarcinii în modelul Fermi-Hubbard

Estimare de utilizare: 5 minute pe un procesor Heron r3. (NOTĂ: Aceasta este doar o estimare. Timpul tău de execuție poate varia.)

Context​

Modelul Fermi-Hubbard descrie electroni care sar pe o rețea, cu o penalizare energetică pentru ocuparea dublă. Pe un lanț unidimensional de LLL situri cu frontiere deschise, hamiltonianul este definit astfel:

H=−∑i=0L−2∑σ∈{↑,↓}th,i(ciσ†ci+1,σ+h.c.)+∑i=0L−1Ui ni↑ni↓−∑i=0L−1∑σμi niσ,H = -\sum_{i=0}^{L-2} \sum_{\sigma \in \{\uparrow,\downarrow\}} t_{h,i} \left( c^\dagger_{i\sigma} c_{i+1,\sigma} + \mathrm{h.c.} \right) + \sum_{i=0}^{L-1} U_i\, n_{i\uparrow} n_{i\downarrow} - \sum_{i=0}^{L-1} \sum_\sigma \mu_i\, n_{i\sigma},H=−i=0∑L−2​σ∈{↑,↓}∑​th,i​(ciσ†​ci+1,σ​+h.c.)+i=0∑L−1​Ui​ni↑​ni↓​−i=0∑L−1​σ∑​μi​niσ​,

unde ciσ†c^\dagger_{i\sigma}ciσ†​ creează un fermion de spin σ\sigmaσ pe situl iii, iar niσ=ciσ†ciσn_{i\sigma} = c^\dagger_{i\sigma} c_{i\sigma}niσ​=ciσ†​ciσ​ îi numără. Cei trei termeni sunt amplitudinea de salt th,it_{h,i}th,i​ pe legătura dintre situl iii și i+1i+1i+1, interacțiunea locală UiU_iUi​ și potențialul chimic μi\mu_iμi​. Tutorialul măsoară energia în unități de tht_hth​ și timpul în unități de 1/th1/t_h1/th​.

Dinamica în timp real a acestui model este greu de calculat clasic. Diagonalizarea exactă se oprește aproape de L≲14L \lesssim 14L≲14 situri, iar după un quench, entropia de încâlcire a unui solver cu rețele tensoriale crește liniar în timp, astfel că dimensiunea legăturii necesară pentru o acuratețe fixă crește exponențial.

Într-o dimensiune, excitațiile elementare sunt spinonii, care poartă spin și nu poartă sarcină, și holonii, care poartă sarcină și nu poartă spin. Cei doi se propagă cu viteze diferite, astfel că o perturbație localizată se împarte într-un front rapid și unul lent. Acest efect se numește separare spin-sarcină, iar acest tutorial o măsoară [1].

Acest tutorial folosește Qiskit Function Dynamics Simulator, care primește hamiltonianul, o stare inițială, o schemă Trotter și o listă de observabile și returnează valori medii. Gestionează intern maparea Jordan-Wigner, trotterizarea, aranjamentul qubiților și suprimarea erorilor, deci în acest tutorial nu ai circuite de construit sau de transpilat.

Pasul 1: Mapează intrările clasice la o problemă cuantică​

Definește hamiltonianul​

Funcția primește modelul ca dicționar cu trei chei. Fiecare acceptă fie un singur float, care se aplică uniform pe lanț, fie o listă care specifică valoarea sit cu sit. Listele au L−1L-1L−1 intrări pentru hopping_amplitude, deoarece un lanț deschis are cu o legătură mai puțin decât situri, și LLL intrări pentru on_site_interaction și chemical_potential.

Acest tutorial folosește un lanț uniform de 31 de situri cu o interacțiune repulsivă U/th=8U/t_h = 8U/th​=8. Un potențial chimic uniform contribuie doar cu o fază globală când numărul de particule este fix, așa că acest exemplu îl setează la zero. Potențialul chimic contează doar când variază de la un sit la altul, de exemplu pentru a adăuga dezordine sau o singură impuritate.

site_count = 31
hopping_amplitude = 1.0
on_site_interaction = 8.0
chemical_potential = 0.0

model = {
    "hopping_amplitude": [hopping_amplitude] * (site_count - 1),
    "on_site_interaction": [on_site_interaction] * site_count,
    "chemical_potential": [chemical_potential] * site_count,
}

print(
    f"{site_count} sites, {2 * site_count} qubits, U/t_h = {on_site_interaction:.0f}"
)
31 sites, 62 qubits, U/t_h = 8

Stabilește schema Trotter​

Dicționarul simulation conține pasul de timp (Δt\Delta tΔt) și numărul de pași Trotter, iar timpul total de evoluție este produsul lor. Pașii mai mari ajung la momente de timp mai târzii la adâncime fixă a circuitului, dar produc o eroare Trotter mai mare, care crește cu UUU deoarece termenii hamiltonianului comută mai puțin. Studiul hardware publicat a folosit Δt=0.15\Delta t = 0.15Δt=0.15 pentru U/th=8U/t_h = 8U/th​=8 [2], iar acest tutorial folosește aceeași valoare. Adâncimea circuitului crește liniar cu numărul de pași și nu depinde deloc de LLL.

time_step = 0.15
step_count = 30

simulation = {"time_step": time_step, "step_count": step_count}

print(
    f"Total evolution time: t = {time_step * step_count:.2f} (units of 1/t_h)"
)
Total evolution time: t = 4.50 (units of 1/t_h)

Pregătește starea inițială​

Fiecare sit conține doi orbitali de spin, deci un lanț de LLL situri folosește 2L2L2L qubiți. Starea inițială este un șir de ocupare Fock cu un caracter pe sit:

empty (e)⟷(ni,↑,ni,↓)=(0,0),up (u)⟷(ni,↑,ni,↓)=(1,0),down (d)⟷(ni,↑,ni,↓)=(0,1),both (b)⟷(ni,↑,ni,↓)=(1,1).\begin{aligned} \texttt{empty (e)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (0,0), \\ \texttt{up (u)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (1,0), \\ \texttt{down (d)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (0,1), \\ \texttt{both (b)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (1,1). \end{aligned}empty (e)up (u)down (d)both (b)​⟷(ni,↑​,ni,↓​)=(0,0),⟷(ni,↑​,ni,↓​)=(1,0),⟷(ni,↑​,ni,↓​)=(0,1),⟷(ni,↑​,ni,↓​)=(1,1).​

Șirul se citește începând cu situl cel mai puțin semnificativ, deci caracterul din dreapta este situl 0, iar indicele fizic al sitului pentru caracterul kkk numărat din stânga este i=L−1−ki = L - 1 - ki=L−1−k. Prin urmare, șirul udud înseamnă că situl 0 este d, situl 1 este u, situl 2 este d, iar situl 3 este u.

Apoi, pregătește o stare Néel la semiumplere, alternând u și d, cu situl central înlocuit de o vacanță. Vacanța este perturbația a cărei propagare este urmărită.

vacancy_site = site_count // 2

# Build in increasing site order, then reverse: the leftmost character of the
# string is the highest site index.
site_occupations = [
    "u" if site % 2 == 0 else "d" for site in range(site_count)
]
site_occupations[vacancy_site] = "e"
initial_state = "".join(reversed(site_occupations))

print(f"Vacancy at site {vacancy_site}")
print(initial_state)

Construiește observabilele​

Fiecare observabilă este un dicționar care reprezintă o sumă ponderată de produse de operatori de ocupare:

O=∑αcα∏(σ,j)∈Tαnj,σ.O = \sum_{\alpha} c_{\alpha} \prod_{(\sigma, j) \in T_{\alpha}} n_{j,\sigma}.O=α∑​cα​(σ,j)∈Tα​∏​nj,σ​.

Fiecare intrare din operators este un termen TαT_{\alpha}Tα​, scris ca o listă de perechi [name, site] care se înmulțesc, iar intrarea corespunzătoare din coefficients este ponderea sa. Cele două nume sunt "Nup" pentru nj,↑n_{j,\uparrow}nj,↑​ și "Ndn" pentru nj,↓n_{j,\downarrow}nj,↓​. O singură observabilă cu un punct n3,↑n_{3,\uparrow}n3,↑​ se scrie astfel:

{"operators": [[["Nup", 3]]], "coefficients": [1.0]}

Celula următoare afișează cel mai mic set complet de intrări pe care îl acceptă funcția, util ca referință de formă în timp ce citești codul care urmează.

minimal_inputs = {

Sunt necesare trei grupuri de observabile. Densitatea de sarcină ni=ni↑+ni↓n_i = n_{i\uparrow} + n_{i\downarrow}ni​=ni↑​+ni↓​ și spinul local Siz=(ni↑−ni↓)/2S^z_i = (n_{i\uparrow} - n_{i\downarrow})/2Siz​=(ni↑​−ni↓​)/2 sunt ambele sume cu doi termeni peste aceiași operatori, diferind doar prin coeficienți. Corelatorul de spin SizSi∗zS^z_i S^z_{i_*}Siz​Si∗​z​ dintre situl iii și situl vacanței se extinde în patru termeni cu două puncte, cu coeficienți ±1/4\pm 1/4±1/4.

Operatorii de ocupare comută, deci ordinea factorilor dintr-un termen este irelevantă, dar ordinea listei observables fixează ordinea valorilor returnate. Codul înregistrează un indice pentru fiecare grup pe măsură ce construiește lista. Corelatorul omite situl vacanței, unde produsul ar repeta un factor.

observables = []
charge_indices = []
spin_indices = []
correlator_indices = []

# Charge density: n_i = n_{i,up} + n_{i,down}
for site in range(site_count):
    charge_indices.append(len(observables))
    observables.append(
        {
            "operators": [[["Nup", site]], [["Ndn", site]]],
            "coefficients": [1.0, 1.0],
        }
    )

# Local spin: S^z_i = (n_{i,up} - n_{i,down}) / 2
for site in range(site_count):
    spin_indices.append(len(observables))
    observables.append(
        {
            "operators": [[["Nup", site]], [["Ndn", site]]],
            "coefficients": [0.5, -0.5],
        }
    )

# Spin correlator: S^z_i S^z_{i_*}, expanded into four two-point terms.
correlator_sites = [
    site for site in range(site_count) if site != vacancy_site
]
for site in correlator_sites:
    correlator_indices.append(len(observables))
    observables.append(
        {
            "operators": [
                [["Nup", site], ["Nup", vacancy_site]],
                [["Nup", site], ["Ndn", vacancy_site]],
                [["Ndn", site], ["Nup", vacancy_site]],
                [["Ndn", site], ["Ndn", vacancy_site]],
            ],
            "coefficients": [0.25, -0.25, -0.25, 0.25],
        }
    )

print(f"{len(observables)} observables")
print("Example correlator:", observables[correlator_indices[0]])
92 observables
Example correlator: {'operators': [[['Nup', 0], ['Nup', 15]], [['Nup', 0], ['Ndn', 15]], [['Ndn', 0], ['Nup', 15]], [['Ndn', 0], ['Ndn', 15]]], 'coefficients': [0.25, -0.25, -0.25, 0.25]}

Pasul 2: Optimizează problema pentru execuția pe hardware cuantic​

Acest tutorial nu are un pas de transpilare. Funcția efectuează intern următorii pași [2], iar tu nu îi poți configura din notebook:

  • Mapează modurile fermionice pe qubiți, într-o ordonare aleasă pentru a menține greutățile Pauli mici pe o rețea heavy-hex

  • Folosește o rețea fermionică de SWAP-uri, astfel încât fiecare termen de salt devine o rotație pe doi qubiți

  • Încorporează lanțul de-a lungul unui traseu care evită qubiții slabi

  • Aplică decuplare dinamică și Pauli twirling în timpul compilării

Tu alegi backendul și numărul de shot-uri. Funcția primește numele backendului ca șir de caractere, deci acest tutorial selectează dispozitivul cel mai puțin ocupat, suficient de mare pentru lanț, și transmite numele acestuia.

Cel mai mic semnal pe care trebuie să îl rezolvi stabilește numărul de shot-uri. Trasorul de sarcină atinge amplitudini apropiate de 0.150.150.15, dar trasorul de spin conectat atinge un maxim în jur de 0.040.040.04, de aproximativ patru ori mai mic. Studiul publicat a folosit 20.000 de shot-uri per circuit din acest motiv [2].

Pasul 4: Postprocesează și returnează rezultatul în formatul clasic dorit​

Reconstruiește corelatorii​

Împarte tabloul plat înapoi în cele trei grupuri folosind indicii înregistrați anterior, apoi formează cei doi corelatori trasori. Trasorul de sarcină este variația densității pe site față de t=0t=0t=0:

Cic(t)=⟨ni↑(t)+ni↓(t)⟩−⟨ni↑(0)+ni↓(0)⟩.C^c_i(t) = \langle n_{i\uparrow}(t) + n_{i\downarrow}(t) \rangle - \langle n_{i\uparrow}(0) + n_{i\downarrow}(0) \rangle.Cic​(t)=⟨ni↑​(t)+ni↓​(t)⟩−⟨ni↑​(0)+ni↓​(0)⟩.

Trasorul de spin este corelatorul conectat dintre fiecare site și site-ul vacanței i∗i_*i∗​:

Cis(t)=4(⟨SizSi∗z⟩−⟨Siz⟩⟨Si∗z⟩).C^s_i(t) = 4 \left( \langle S^z_i S^z_{i_*} \rangle - \langle S^z_i \rangle \langle S^z_{i_*} \rangle \right).Cis​(t)=4(⟨Siz​Si∗​z​⟩−⟨Siz​⟩⟨Si∗​z​⟩).

Ambii sunt construiți din operatori în baza Fock, deci provin din aceleași șiruri de biți măsurate, iar al doilea nu costă nicio execuție suplimentară pe hardware.

Când ai construit observabilele, codul a înregistrat poziția fiecărui operator de sarcină (charge_indices), de spin (spin_indices) și de corelație de spin (correlator_indices) în listă. Deoarece simulatorul returnează valorile medii în aceeași ordine, poți folosi aceste poziții pentru a extrage rezultatele corespunzătoare. Pentru corelațiile de spin, codul folosește și correlator_sites pentru a plasa fiecare rezultat în poziția corectă a rețelei și lasă vacanța ca NaN.

expectation_values = np.asarray(
    result["observable_expectation_values"], dtype=float
)
times = np.arange(expectation_values.shape[1]) * time_step

charge_density = expectation_values[charge_indices]
local_spin = expectation_values[spin_indices]
spin_correlator = np.full_like(charge_density, np.nan)
spin_correlator[correlator_sites] = expectation_values[correlator_indices]

# Charge tracer: change in per-site density relative to t = 0.
charge_tracer = charge_density - charge_density[:, [0]]

# Spin tracer: connected correlator with the vacancy site.
spin_tracer = 4.0 * (spin_correlator - local_spin * local_spin[vacancy_site])
spin_tracer[vacancy_site] = np.nan

print(
    f"{expectation_values.shape[0]} observables, "
    f"{expectation_values.shape[1]} time points up to t = {times[-1]:.2f}"
)
print(
    f"Peak amplitudes: charge {np.nanmax(np.abs(charge_tracer)):.3f}, "
    f"spin {np.nanmax(np.abs(spin_tracer)):.3f}"
)

Vizualizează fronturile de undă​

Dacă reprezinți fiecare corelator ca hartă termică a spațiului și timpului, conul de lumină este vizibil direct. Timpul curge în jos, iar axa orizontală este poziția de-a lungul lanțului.

def plot_tracer(axis, tracer, title):
    """Draw one tracer correlator as a space-time heatmap, time flowing down."""
    # Scale from the off-centre sites. The vacancy site carries an order-one
    # change in charge density and is left to clip rather than set the scale.
    off_center = np.ones(site_count, dtype=bool)
    off_center[vacancy_site] = False
    limit = np.nanpercentile(np.abs(tracer[off_center]), 98)

    colormap = qv.QCTRL_DIVERGENT_COLORMAP.reversed().copy()
    colormap.set_bad("0.82")  # the spin tracer has no value at the vacancy

    image = axis.imshow(
        tracer.T,
        aspect="auto",
        origin="upper",
        cmap=colormap,
        vmin=-limit,
        vmax=limit,
        extent=(-0.5, site_count - 0.5, times[-1], times[0]),
        interpolation="nearest",
    )

    axis.annotate(
        "vacancy",
        xy=(vacancy_site, times[-1]),
        xytext=(vacancy_site, times[-1] + 0.55),
        ha="center",
        va="top",
        fontsize=8,
        annotation_clip=False,
        arrowprops=dict(arrowstyle="-", lw=0.8, color="0.4"),
    )

    axis.set_title(title)
    axis.set_xlabel("Site")
    return image

Extrage vitezele fronturilor de undă​

Transformă hărțile termice în numere urmând protocolul de detecție din studiul publicat [2]. La fiecare felie de timp, simetrizează profilul spațial în jurul vacanței, ceea ce elimină prin mediere partea antisimetrică a zgomotului hardware, normalizează după cea mai mare amplitudine din afara centrului și înregistrează cel mai exterior site aflat peste un prag. Detecțiile sunt apoi tăiate în secvențe de pași de timp consecutivi, iar doar cea mai lungă secvență este ajustată, ceea ce ține tranzitoriul de la timpuri scurte în afara rezultatului.

def front_distance(profile, center, threshold):
    """Distance from `center` to the outermost site above a relative threshold."""
    values = np.nan_to_num(np.asarray(profile, dtype=float))
    length = values.size

    symmetrized = values.copy()
    for site in range(length):
        mirror = 2 * center - site
        if 0 <= mirror < length:
            symmetrized[site] = 0.5 * (values[site] + values[mirror])

    amplitude = np.abs(symmetrized)
    off_center = np.ones(length, dtype=bool)
    off_center[center] = False

    peak = amplitude[off_center].max()
    if peak <= 0.0:
        return np.nan
    above = np.flatnonzero((amplitude / peak > threshold) & off_center)
    return float(np.abs(above - center).max()) if above.size else np.nan

def longest_run(mask):
    """Indices of the longest run of consecutive True values."""
    best, current = [], []
    for index, keep in enumerate(mask):
        current = current + [index] if keep else []
        if len(current) > len(best):
            best = current
    return np.array(best, dtype=int)

def front_velocity(tracer, center, threshold=0.3, quantile=0.75, min_block=5):
    """Fit front position against time, using only the longest contiguous run."""
    distances = np.array(
        [
            front_distance(tracer[:, k], center, threshold)
            for k in range(tracer.shape[1])
        ]
    )
    edge = max(center, tracer.shape[0] - 1 - center)
    usable = (
        np.isfinite(distances) & (distances >= 2) & (distances <= edge - 2)
    )

    block = longest_run(usable)
    if block.size < min_block:
        return np.nan, distances, np.array([], dtype=int), np.nan

    candidates = [
        stats.theilslopes(distances[block[:k]], times[block[:k]]).slope
        for k in range(min_block, block.size + 1)
    ]
    cutoff = np.quantile(candidates, quantile)
    keep = max(i for i, value in enumerate(candidates) if value >= cutoff)

    fit_block = block[: keep + min_block]
    slope, intercept = np.polyfit(times[fit_block], distances[fit_block], 1)
    return float(slope), distances, fit_block, float(intercept)

Viteza ajustată depinde de pragul de detecție și de cuantila de tăiere, iar această sensibilitate domină zgomotul de eșantionare. Parcurge ambele și raportează mediana împreună cu întreaga înfășurătoare, așa cum face analiza publicată.

thresholds = [0.15, 0.225, 0.30, 0.375, 0.45]
quantiles = [0.60, 0.675, 0.75, 0.825, 0.90]

def velocity_envelope(tracer, center):
    """Median, minimum, and maximum velocity over the parameter scan."""
    values = [
        front_velocity(tracer, center, threshold=p, quantile=q)[0]
        for p in thresholds
        for q in quantiles
    ]
    values = np.array([v for v in values if np.isfinite(v)])
    if values.size == 0:
        return np.nan, np.nan, np.nan
    return float(np.median(values)), float(values.min()), float(values.max())

def plot_tracer_front(axis, tracer, front, block, velocity, intercept, title):
    """Overlay the detected wavefront and the fitted cone on a tracer heatmap."""
    image = plot_tracer(axis, tracer, title)

    excluded = np.setdiff1d(np.arange(front.size), block)
    for index, filled in ((block, True), (excluded, False)):

Frontul sarcinii îl depășește pe cel al spinului. O gaură într-un fundal Mott unidimensional nu se propagă ca un electron. În schimb, se fracționalizează într-un holon care poartă sarcina și un spinon care poartă perturbația de spin, iar la U/th=8U/t_h = 8U/th​=8 spinonul este cel mai lent dintre cei doi.

Ordinea depinde de interacțiune. La U=0U = 0U=0, modelul este de fermioni liberi cu vc=2v_c = 2vc​=2 și vs=4v_s = 4vs​=4, deci spinul este mai rapid. Repulsia suprimă transportul de spin și lasă transportul de sarcină aproape neatins, iar la U/th=8U/t_h = 8U/th​=8 valorile publicate pe hardware sunt vc=1.78v_c = 1.78vc​=1.78 și vs=1.46v_s = 1.46vs​=1.46 [2]. Rularea repetată cu mai multe valori ale lui UUU și reprezentarea grafică a lui vs/vcv_s / v_cvs​/vc​ cartografiază tranziția.

Ține cont de aceste rezerve privind valorile. Detecția bazată pe prag este ușor părtinitoare spre valori mici, deci este de așteptat o viteză a sarcinii cu câteva procente sub valoarea publicată. Înfășurătoarea spinului este largă deoarece corelatorul conectat se află mai aproape de pragul de zgomot, motiv pentru care se citează mediana scanării, nu o singură ajustare.
